## Série A — Formule, image et antécédent

<p class="auto-meta">⏱ 6 min · Calculatrice interdite</p>

<div class="auto-consigne" markdown>
**Consigne.** Utiliser la notation fonctionnelle avec précision.
</div>

<ol class="auto-questions">
<li value="1">Soit <span class="arithmatex">\(f(x)=2x+3\)</span>. Calculer <span class="arithmatex">\(f(4)\)</span>.</li>
<li value="2">Soit <span class="arithmatex">\(f(x)=2x+3\)</span>. Déterminer l'antécédent de <span class="arithmatex">\(9\)</span>.</li>
<li value="3">Soit <span class="arithmatex">\(g(x)=x^2-4\)</span>. Calculer <span class="arithmatex">\(g(-2)\)</span>.</li>
<li value="4">Compléter : si <span class="arithmatex">\(h(5)=12\)</span>, alors <span class="arithmatex">\(12\)</span> est l'… de <span class="arithmatex">\(5\)</span>.</li>
<li value="5">Compléter : si <span class="arithmatex">\(h(5)=12\)</span>, alors <span class="arithmatex">\(5\)</span> est un … de <span class="arithmatex">\(12\)</span>.</li>
<li value="6">Le coût de <span class="arithmatex">\(q\)</span> articles est <span class="arithmatex">\(C(q)=12q+150\)</span>. Calculer <span class="arithmatex">\(C(10)\)</span>.</li>
</ol>

??? tip "Coup de pouce"

    <p><strong>Conseils</strong></p><ul><li>Pour une image, remplacer <span class="arithmatex">\(x\)</span>.</li><li>Pour un antécédent, résoudre une équation.</li><li>Respecter le vocabulaire.</li></ul>
    <p><strong>Vigilance</strong></p><p>Une image est une valeur obtenue ; un antécédent est une valeur de départ.</p>

??? success "Corrigé de la série A"

    <ol class="auto-corrige">
    <li value="1"><span class="arithmatex">\(f(4)=\)</span><wbr><span class="arithmatex">\(2\times4+3=\)</span><wbr><span class="arithmatex">\(\boxed{11}\)</span>.</li>
    <li value="2"><span class="arithmatex">\(2x+3=9\Longleftrightarrow\)</span><wbr><span class="arithmatex">\( x=3\)</span> : antécédent <span class="arithmatex">\(\boxed{3}\)</span>.</li>
    <li value="3"><span class="arithmatex">\(g(-2)=(-2)^2-4=\boxed{0}\)</span>.</li>
    <li value="4"><span class="arithmatex">\(12\)</span> est l'<strong class="auto-resultat">image</strong> de <span class="arithmatex">\(5\)</span>.</li>
    <li value="5"><span class="arithmatex">\(5\)</span> est un <strong class="auto-resultat">antécédent</strong> de <span class="arithmatex">\(12\)</span>.</li>
    <li value="6"><span class="arithmatex">\(C(10)=\)</span><wbr><span class="arithmatex">\(12\times10+150=\)</span><wbr><span class="arithmatex">\(\boxed{270}\)</span> €.</li>
    </ol>
    <div class="auto-methode"><strong>Méthode.</strong> Calculer <span class="arithmatex">\(f(a)\)</span> signifie remplacer chaque <span class="arithmatex">\(x\)</span> par <span class="arithmatex">\(a\)</span>. Chercher un antécédent signifie résoudre <span class="arithmatex">\(f(x)=k\)</span>.</div>
    <div class="auto-vigilance"><strong>Vigilance.</strong> Toujours distinguer la fonction <span class="arithmatex">\(f\)</span>, sa courbe <span class="arithmatex">\(\mathcal C_f\)</span>, l'image et l'antécédent.</div>

## Série B — Lectures graphiques

<p class="auto-meta">⏱ 8 min · Calculatrice interdite</p>

<div class="auto-consigne" markdown>
**Consigne.** Lire graphiquement. Les réponses exactes sont visibles sur la courbe.
</div>

<div class="auto-figure"><img src="../figures/N04-fonctions-registres-lectures-fdef1e17e2.svg" alt="Figure de la série B" width="371"></div>

<ol class="auto-questions">
<li value="1">Lire <span class="arithmatex">\(f(-4)\)</span>.</li>
<li value="2">Lire <span class="arithmatex">\(f(0)\)</span>.</li>
<li value="3">Donner les antécédents de <span class="arithmatex">\(0\)</span>.</li>
<li value="4">Résoudre <span class="arithmatex">\(f(x)=2\)</span>.</li>
<li value="5">Sur quels intervalles <span class="arithmatex">\(f(x)&gt;0\)</span> ?</li>
<li value="6">Donner un intervalle où <span class="arithmatex">\(f\)</span> est décroissante.</li>
</ol>

??? tip "Coup de pouce"

    <p><strong>Conseils</strong></p><p>Image : lecture verticale. Antécédent : lecture horizontale.</p>
    <p><strong>Vigilance</strong></p><p>Pour <span class="arithmatex">\(f(x)&gt;0\)</span>, repérer les portions au-dessus de l'axe des abscisses.</p>

??? success "Corrigé de la série B"

    <div class="auto-figure"><img src="../figures/N04-fonctions-registres-lectures-fdef1e17e2.svg" alt="Figure de la série B" width="371"></div>
    <ol class="auto-corrige">
    <li value="1"><span class="arithmatex">\(f(-4)=\boxed{-2}\)</span>.</li>
    <li value="2"><span class="arithmatex">\(f(0)=\boxed{2}\)</span>.</li>
    <li value="3"><span class="arithmatex">\(\boxed{\{-3;1;3\}}\)</span>.</li>
    <li value="4"><span class="arithmatex">\(\boxed{[-2;0]\cup\{4\}}\)</span>.</li>
    <li value="5"><span class="arithmatex">\(\boxed{]-3;1[\cup]3;4]}\)</span>.</li>
    <li value="6">Par exemple <span class="arithmatex">\(\boxed{[0;2]}\)</span>.</li>
    </ol>
    <div class="auto-methode"><strong>Méthode.</strong> Tracer mentalement une verticale pour une image, une horizontale pour un antécédent.</div>
    <div class="auto-vigilance"><strong>Vigilance.</strong> Une portion horizontale peut fournir une infinité de solutions à <span class="arithmatex">\(f(x)=k\)</span>.</div>

## Série C — Passer d'un registre à l'autre

<p class="auto-meta">⏱ 7 min · Calculatrice interdite</p>

<div class="auto-consigne" markdown>
**Consigne.** On considère le coût <span class="arithmatex">\(C(x)=5x+120\)</span>, en euros, pour produire <span class="arithmatex">\(x\)</span> objets.
</div>

<ol class="auto-questions">
<li value="1">Calculer <span class="arithmatex">\(C(20)\)</span>.</li>
<li value="2">Déterminer l'antécédent de <span class="arithmatex">\(220\)</span>.</li>
<li value="3">Interpréter la phrase <span class="arithmatex">\(C(30)=270\)</span>.</li>
<li value="4">Réduire <span class="arithmatex">\(3x+4x-5\)</span>.</li>
<li value="5">Résoudre <span class="arithmatex">\((x-2)(x+5)=0\)</span>.</li>
<li value="6">Un prix de <span class="arithmatex">\(200\)</span> € augmente de <span class="arithmatex">\(10\,\%\)</span>. Nouveau prix ?</li>
</ol>

??? tip "Coup de pouce"

    <p><strong>Conseils</strong></p><ul><li>Traduire chaque question dans le bon registre.</li><li>Conserver les unités.</li><li>Réactiver les méthodes précédentes.</li></ul>
    <p><strong>Vigilance</strong></p><p>Une égalité fonctionnelle doit être interprétée dans le contexte, pas seulement calculée.</p>

??? success "Corrigé de la série C"

    <ol class="auto-corrige">
    <li value="1"><span class="arithmatex">\(C(20)=\)</span><wbr><span class="arithmatex">\(5\times20+120=\)</span><wbr><span class="arithmatex">\(\boxed{220}\)</span> €.</li>
    <li value="2"><span class="arithmatex">\(5x+120=220\Longleftrightarrow\)</span><wbr><span class="arithmatex">\( x=\boxed{20}\)</span>.</li>
    <li value="3">Produire <span class="arithmatex">\(\boxed{30}\)</span> objets coûte <span class="arithmatex">\(\boxed{270}\)</span> €.</li>
    <li value="4"><span class="arithmatex">\(3x+4x-5=\boxed{7x-5}\)</span>.</li>
    <li value="5"><span class="arithmatex">\(x=2\)</span> ou <span class="arithmatex">\(x=-5\)</span>, donc <span class="arithmatex">\(\mathscr S=\)</span><wbr><span class="arithmatex">\(\boxed{\{-5;2\}}\)</span>.</li>
    <li value="6"><span class="arithmatex">\(200\times1{,}10=\)</span><wbr><span class="arithmatex">\(\boxed{220}\)</span> €.</li>
    </ol>
    <div class="auto-methode"><strong>Méthode.</strong> Un même objet fonction peut être décrit par une formule, un tableau, un graphique ou une phrase.</div>
    <div class="auto-vigilance"><strong>Vigilance.</strong> Dans un contexte, l'antécédent peut être soumis à une contrainte, par exemple <span class="arithmatex">\(x\geqslant0\)</span>.</div>

## Série D — Type épreuve anticipée – QCM cumulatif

<p class="auto-meta">⏱ 7 min · Calculatrice interdite</p>

<div class="auto-consigne" markdown>
**Consigne.** Pour chaque question, choisir une seule réponse. Aucune justification n'est demandée.
</div>

<ol class="auto-questions">
<li value="1">Si <span class="arithmatex">\(f(3)=7\)</span>, alors :<ol class="auto-choix" type="A"><li><span class="arithmatex">\(3\)</span> est l'image de <span class="arithmatex">\(7\)</span></li><li><span class="arithmatex">\(7\)</span> est l'image de <span class="arithmatex">\(3\)</span></li><li><span class="arithmatex">\(f(7)=3\)</span></li><li><span class="arithmatex">\(3=7\)</span></li></ol></li>
<li value="2">Pour <span class="arithmatex">\(f(x)=x^2+1\)</span>, <span class="arithmatex">\(f(-2)\)</span> vaut :<ol class="auto-choix" type="A"><li><span class="arithmatex">\(-3\)</span></li><li><span class="arithmatex">\(-5\)</span></li><li><span class="arithmatex">\(3\)</span></li><li><span class="arithmatex">\(5\)</span></li></ol></li>
<li value="3">Les solutions de <span class="arithmatex">\((x-4)(x+1)=0\)</span> sont :<ol class="auto-choix" type="A"><li><span class="arithmatex">\(4\)</span> et <span class="arithmatex">\(-1\)</span></li><li><span class="arithmatex">\(-4\)</span> et <span class="arithmatex">\(1\)</span></li><li><span class="arithmatex">\(4\)</span> seulement</li><li><span class="arithmatex">\(-1\)</span> seulement</li></ol></li>
<li value="4">Le signe de <span class="arithmatex">\(2x-6\)</span> pour <span class="arithmatex">\(x=1\)</span> est :<ol class="auto-choix" type="A"><li>positif</li><li>nul</li><li>négatif</li><li>indéterminé</li></ol></li>
<li value="5">Une hausse de <span class="arithmatex">\(5\,\%\)</span>, puis de <span class="arithmatex">\(10\,\%\)</span>, donne le coefficient :<ol class="auto-choix" type="A"><li><span class="arithmatex">\(1{,}15\)</span></li><li><span class="arithmatex">\(1{,}155\)</span></li><li><span class="arithmatex">\(0{,}95\)</span></li><li><span class="arithmatex">\(1{,}50\)</span></li></ol></li>
<li value="6"><span class="arithmatex">\(30\,\%\)</span> de <span class="arithmatex">\(90\)</span> vaut :<ol class="auto-choix" type="A"><li><span class="arithmatex">\(18\)</span></li><li><span class="arithmatex">\(27\)</span></li><li><span class="arithmatex">\(30\)</span></li><li><span class="arithmatex">\(60\)</span></li></ol></li>
</ol>

??? tip "Coup de pouce"

    <p><strong>Conseils</strong></p><ul><li>Identifier le registre : formule, équation ou pourcentage.</li><li>Une seule réponse est correcte.</li><li>Contrôler les signes.</li></ul>
    <p><strong>Vigilance</strong></p><p>Dans <span class="arithmatex">\(f(-2)\)</span>, les parenthèses autour de <span class="arithmatex">\(-2\)</span> sont indispensables.</p>

??? success "Corrigé de la série D"

    <ol class="auto-corrige">
    <li value="1"><strong class="auto-resultat">Réponse B</strong> : <span class="arithmatex">\(7\)</span> est l'image de <span class="arithmatex">\(3\)</span>.</li>
    <li value="2"><strong class="auto-resultat">Réponse D</strong> : <span class="arithmatex">\((-2)^2+1=5\)</span>.</li>
    <li value="3"><strong class="auto-resultat">Réponse A</strong> : produit nul.</li>
    <li value="4"><strong class="auto-resultat">Réponse C</strong> : <span class="arithmatex">\(2\times1-6=-4\)</span>.</li>
    <li value="5"><strong class="auto-resultat">Réponse B</strong> : <span class="arithmatex">\(1{,}05\times1{,}10=\)</span><wbr><span class="arithmatex">\(1{,}155\)</span>.</li>
    <li value="6"><strong class="auto-resultat">Réponse B</strong> : <span class="arithmatex">\(0{,}30\times90=27\)</span>.</li>
    </ol>
    <div class="auto-methode"><strong>Méthode.</strong> La première étape consiste à reconnaître ce que la question demande : calcul d'image, équation, signe ou évolution.</div>
    <div class="auto-vigilance"><strong>Vigilance.</strong> Les automatismes cumulatifs entretiennent les acquis des notions précédentes.</div>
