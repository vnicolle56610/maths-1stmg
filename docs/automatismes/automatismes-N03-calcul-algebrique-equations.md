## Série A — Réduire, développer et factoriser

<p class="auto-meta">⏱ 6 min · Calculatrice interdite</p>

<div class="auto-consigne" markdown>
**Consigne.** Effectuer les transformations demandées et donner une expression simplifiée.
</div>

<ol class="auto-questions">
<li value="1">Réduire <span class="arithmatex">\(3x+5x\)</span>.</li>
<li value="2">Développer <span class="arithmatex">\(4(x+3)\)</span>.</li>
<li value="3">Réduire <span class="arithmatex">\(5x-2+3x+7\)</span>.</li>
<li value="4">Factoriser <span class="arithmatex">\(6x+18\)</span>.</li>
<li value="5">Développer puis réduire <span class="arithmatex">\(3(2x-1)-x\)</span>.</li>
<li value="6">Calculer <span class="arithmatex">\(A=2x^2-3\)</span> pour <span class="arithmatex">\(x=-2\)</span>.</li>
</ol>

??? tip "Coup de pouce"

    <p><strong>Conseils</strong></p><ul><li>Regrouper seulement les termes semblables.</li><li>Distribuer le facteur à chaque terme.</li><li>Pour factoriser, chercher un facteur commun.</li></ul>
    <p><strong>Vigilance</strong></p><p>Dans <span class="arithmatex">\(2x^2\)</span>, le carré porte sur <span class="arithmatex">\(x\)</span>, pas sur le coefficient <span class="arithmatex">\(2\)</span>.</p>

??? success "Corrigé de la série A"

    <ol class="auto-corrige">
    <li value="1"><span class="arithmatex">\(3x+5x=\boxed{8x}\)</span>.</li>
    <li value="2"><span class="arithmatex">\(4(x+3)=\boxed{4x+12}\)</span>.</li>
    <li value="3"><span class="arithmatex">\(5x-2+3x+7=\boxed{8x+5}\)</span>.</li>
    <li value="4"><span class="arithmatex">\(6x+18=\boxed{6(x+3)}\)</span>.</li>
    <li value="5"><span class="arithmatex">\(3(2x-1)-x=\)</span><wbr><span class="arithmatex">\(6x-3-x=\)</span><wbr><span class="arithmatex">\(\boxed{5x-3}\)</span>.</li>
    <li value="6"><span class="arithmatex">\(2(-2)^2-3=8-3=\boxed{5}\)</span>.</li>
    </ol>
    <div class="auto-methode"><strong>Méthode.</strong> Développer revient à supprimer des parenthèses par distributivité ; factoriser est l'opération inverse.</div>
    <div class="auto-vigilance"><strong>Vigilance.</strong> Pour remplacer <span class="arithmatex">\(x\)</span> par un nombre négatif, conserver les parenthèses.</div>

## Série B — Équations et produit nul

<p class="auto-meta">⏱ 7 min · Calculatrice interdite</p>

<div class="auto-consigne" markdown>
**Consigne.** Résoudre dans <span class="arithmatex">\(\mathbb R\)</span>. Donner l'ensemble des solutions.
</div>

<ol class="auto-questions">
<li value="1"><span class="arithmatex">\(3x-12=0\)</span></li>
<li value="2"><span class="arithmatex">\(5(x-2)=0\)</span></li>
<li value="3"><span class="arithmatex">\((x-5)(x+2)=0\)</span></li>
<li value="4"><span class="arithmatex">\(x(2x+6)=0\)</span></li>
<li value="5"><span class="arithmatex">\((3x-1)(x+4)=0\)</span></li>
<li value="6"><span class="arithmatex">\(x^2-9=0\)</span></li>
</ol>

??? tip "Coup de pouce"

    <p><strong>Conseils</strong></p><ul><li>Isoler l'inconnue dans une équation simple.</li><li>Un produit est nul si l'un de ses facteurs est nul.</li><li>Reconnaître une différence de deux carrés.</li></ul>
    <p><strong>Vigilance</strong></p><p>Ne jamais conclure <span class="arithmatex">\(a=0\)</span> ou <span class="arithmatex">\(b=0\)</span> à partir d'une somme <span class="arithmatex">\(a+b=0\)</span>.</p>

??? success "Corrigé de la série B"

    <ol class="auto-corrige">
    <li value="1"><span class="arithmatex">\(3x=12\Longleftrightarrow\)</span><wbr><span class="arithmatex">\( x=4\)</span>, donc <span class="arithmatex">\(\mathscr S=\boxed{\{4\}}\)</span>.</li>
    <li value="2"><span class="arithmatex">\(x-2=0\)</span>, donc <span class="arithmatex">\(\mathscr S=\boxed{\{2\}}\)</span>.</li>
    <li value="3"><span class="arithmatex">\(x=5\)</span> ou <span class="arithmatex">\(x=-2\)</span>, donc <span class="arithmatex">\(\mathscr S=\)</span><wbr><span class="arithmatex">\(\boxed{\{-2;5\}}\)</span>.</li>
    <li value="4"><span class="arithmatex">\(x=0\)</span> ou <span class="arithmatex">\(2x+6=0\)</span>, donc <span class="arithmatex">\(\mathscr S=\)</span><wbr><span class="arithmatex">\(\boxed{\{-3;0\}}\)</span>.</li>
    <li value="5"><span class="arithmatex">\(x=\frac13\)</span> ou <span class="arithmatex">\(x=-4\)</span>, donc <span class="arithmatex">\(\mathscr S=\)</span><wbr><span class="arithmatex">\(\boxed{\{-4;\frac13\}}\)</span>.</li>
    <li value="6"><span class="arithmatex">\((x-3)(x+3)=0\)</span>, donc <span class="arithmatex">\(\mathscr S=\)</span><wbr><span class="arithmatex">\(\boxed{\{-3;3\}}\)</span>.</li>
    </ol>
    <div class="auto-methode"><strong>Méthode.</strong> Pour une équation produit nul, résoudre séparément chaque facteur égal à zéro, puis réunir les solutions.</div>
    <div class="auto-vigilance"><strong>Vigilance.</strong> La méthode du produit nul exige que le second membre soit exactement <span class="arithmatex">\(0\)</span>.</div>

## Série C — Signe d'expressions et réactivation

<p class="auto-meta">⏱ 7 min · Calculatrice interdite</p>

<div class="auto-consigne" markdown>
**Consigne.** Répondre sans dresser un tableau complet lorsque le signe se lit immédiatement.
</div>

<ol class="auto-questions">
<li value="1">Pour quelles valeurs de <span class="arithmatex">\(x\)</span> a-t-on <span class="arithmatex">\(3x-6&gt;0\)</span> ?</li>
<li value="2">Quel est le signe de <span class="arithmatex">\(-2x+8\)</span> lorsque <span class="arithmatex">\(x=5\)</span> ?</li>
<li value="3">Sur <span class="arithmatex">\([0;20]\)</span>, le bénéfice <span class="arithmatex">\(B(x)=(x-4)(20-x)\)</span> est positif pour quelles valeurs ?</li>
<li value="4">Une hausse de <span class="arithmatex">\(12\,\%\)</span> correspond à quel coefficient multiplicateur ?</li>
<li value="5">Un prix de <span class="arithmatex">\(80\)</span> € baisse de <span class="arithmatex">\(15\,\%\)</span>. Nouveau prix ?</li>
<li value="6">Quel taux transforme <span class="arithmatex">\(50\)</span> en <span class="arithmatex">\(60\)</span> ?</li>
</ol>

??? tip "Coup de pouce"

    <p><strong>Conseils</strong></p><ul><li>Repérer les zéros des facteurs.</li><li>Tester le signe dans chaque zone utile.</li><li>Pour un taux, revenir à la valeur initiale.</li></ul>
    <p><strong>Vigilance</strong></p><p>Le signe d'un produit dépend du signe de chacun de ses facteurs.</p>

??? success "Corrigé de la série C"

    <ol class="auto-corrige">
    <li value="1"><span class="arithmatex">\(3x-6&gt;0\Longleftrightarrow\)</span><wbr><span class="arithmatex">\( x&gt;2\)</span>, soit <span class="arithmatex">\(\boxed{]2;+\infty[}\)</span>.</li>
    <li value="2"><span class="arithmatex">\(-2\times5+8=-2\)</span> : l'expression est <strong class="auto-resultat">négative</strong>.</li>
    <li value="3">Les deux facteurs sont positifs pour <span class="arithmatex">\(4&lt;x&lt;20\)</span> : <span class="arithmatex">\(\boxed{]4;20[}\)</span>.</li>
    <li value="4"><span class="arithmatex">\(1+0{,}12=\boxed{1{,}12}\)</span>.</li>
    <li value="5"><span class="arithmatex">\(80\times0{,}85=\)</span><wbr><span class="arithmatex">\(\boxed{68}\)</span> €.</li>
    <li value="6"><span class="arithmatex">\(\frac{60-50}{50}=0{,}20\)</span>, soit <span class="arithmatex">\(\boxed{20\,\%}\)</span>.</li>
    </ol>
    <div class="auto-methode"><strong>Méthode.</strong> Pour le signe d'un produit, placer ses zéros, puis combiner les signes des facteurs.</div>
    <div class="auto-vigilance"><strong>Vigilance.</strong> Dans un contexte, préciser si les valeurs qui annulent l'expression sont incluses ou non.</div>

## Série D — Type épreuve anticipée – QCM cumulatif

<p class="auto-meta">⏱ 7 min · Calculatrice interdite</p>

<div class="auto-consigne" markdown>
**Consigne.** Pour chaque question, choisir une seule réponse. Aucune justification n'est demandée.
</div>

<ol class="auto-questions">
<li value="1"><span class="arithmatex">\(2(x+5)\)</span> vaut :<ol class="auto-choix" type="A"><li><span class="arithmatex">\(2x+5\)</span></li><li><span class="arithmatex">\(2x+10\)</span></li><li><span class="arithmatex">\(x+10\)</span></li><li><span class="arithmatex">\(7x\)</span></li></ol></li>
<li value="2">Les solutions de <span class="arithmatex">\((x-1)(x+3)=0\)</span> sont :<ol class="auto-choix" type="A"><li><span class="arithmatex">\(1\)</span> seulement</li><li><span class="arithmatex">\(-3\)</span> seulement</li><li><span class="arithmatex">\(1\)</span> et <span class="arithmatex">\(-3\)</span></li><li><span class="arithmatex">\(3\)</span> et <span class="arithmatex">\(-1\)</span></li></ol></li>
<li value="3">Le coefficient d'une baisse de <span class="arithmatex">\(8\,\%\)</span> est :<ol class="auto-choix" type="A"><li><span class="arithmatex">\(0{,}08\)</span></li><li><span class="arithmatex">\(0{,}92\)</span></li><li><span class="arithmatex">\(1{,}08\)</span></li><li><span class="arithmatex">\(1{,}8\)</span></li></ol></li>
<li value="4">Deux hausses de <span class="arithmatex">\(10\,\%\)</span> donnent :<ol class="auto-choix" type="A"><li><span class="arithmatex">\(20\,\%\)</span></li><li><span class="arithmatex">\(21\,\%\)</span></li><li><span class="arithmatex">\(10\,\%\)</span></li><li><span class="arithmatex">\(0\,\%\)</span></li></ol></li>
<li value="5"><span class="arithmatex">\(18\)</span> représente de <span class="arithmatex">\(24\)</span> :<ol class="auto-choix" type="A"><li><span class="arithmatex">\(60\,\%\)</span></li><li><span class="arithmatex">\(70\,\%\)</span></li><li><span class="arithmatex">\(75\,\%\)</span></li><li><span class="arithmatex">\(80\,\%\)</span></li></ol></li>
<li value="6">L'intersection de <span class="arithmatex">\([0;4]\)</span> et <span class="arithmatex">\(]2;6]\)</span> est :<ol class="auto-choix" type="A"><li><span class="arithmatex">\([0;6]\)</span></li><li><span class="arithmatex">\(]2;4]\)</span></li><li><span class="arithmatex">\([2;4]\)</span></li><li><span class="arithmatex">\(]0;6]\)</span></li></ol></li>
</ol>

??? tip "Coup de pouce"

    <p><strong>Conseils</strong></p><ul><li>Reconnaître la structure avant de calculer.</li><li>Une seule réponse est correcte.</li><li>Contrôler les bornes des intervalles.</li></ul>
    <p><strong>Vigilance</strong></p><p>Un QCM peut mélanger calcul algébrique, pourcentages et logique.</p>

??? success "Corrigé de la série D"

    <ol class="auto-corrige">
    <li value="1"><strong class="auto-resultat">Réponse B</strong> : distributivité.</li>
    <li value="2"><strong class="auto-resultat">Réponse C</strong> : chaque facteur peut être nul.</li>
    <li value="3"><strong class="auto-resultat">Réponse B</strong> : <span class="arithmatex">\(1-0{,}08=0{,}92\)</span>.</li>
    <li value="4"><strong class="auto-resultat">Réponse B</strong> : <span class="arithmatex">\(1{,}1^2=1{,}21\)</span>.</li>
    <li value="5"><strong class="auto-resultat">Réponse C</strong> : <span class="arithmatex">\(\frac{18}{24}=\frac34\)</span>.</li>
    <li value="6"><strong class="auto-resultat">Réponse B</strong> : valeurs strictement supérieures à <span class="arithmatex">\(2\)</span> et au plus égales à <span class="arithmatex">\(4\)</span>.</li>
    </ol>
    <div class="auto-methode"><strong>Méthode.</strong> Chercher d'abord la propriété adaptée : distributivité, produit nul, coefficient multiplicateur ou intersection.</div>
    <div class="auto-vigilance"><strong>Vigilance.</strong> Une réponse plausible n'est pas nécessairement exacte : vérifier un calcul court suffit souvent.</div>
