## Série A — Réactivation : fonctions et calcul

<p class="auto-meta">⏱ 6 min · Calculatrice interdite</p>

<div class="auto-consigne" markdown>
**Consigne.** Réactiver les calculs utiles avant le second degré.
</div>

<ol class="auto-questions">
<li value="1">Soit <span class="arithmatex">\(f(x)=2x+3\)</span>. Calculer <span class="arithmatex">\(f(5)\)</span>.</li>
<li value="2">Si <span class="arithmatex">\(f(0)=3\)</span> et <span class="arithmatex">\(f(4)=11\)</span>, calculer le taux de variation entre <span class="arithmatex">\(0\)</span> et <span class="arithmatex">\(4\)</span>.</li>
<li value="3">Augmenter de <span class="arithmatex">\(20\,\%\)</span>, c'est multiplier par quel coefficient ?</li>
<li value="4">Résoudre mentalement <span class="arithmatex">\(2x-6=0\)</span>.</li>
<li value="5">Quel est le signe de <span class="arithmatex">\(x-4\)</span> pour <span class="arithmatex">\(x=6\)</span> ?</li>
<li value="6">Soit <span class="arithmatex">\(h(x)=x^2\)</span>. Calculer <span class="arithmatex">\(h(-4)\)</span>.</li>
</ol>

??? tip "Coup de pouce"

    <p><strong>Conseils</strong></p><ul><li>Commencer par remplacer <span class="arithmatex">\(x\)</span>.</li><li>Pour un carré, le résultat est positif.</li><li>Réactiver coefficients et signes.</li></ul>
    <p><strong>Vigilance</strong></p><p>Ne pas écrire <span class="arithmatex">\((-4)^2=-16\)</span>.</p>

??? success "Corrigé de la série A"

    <ol class="auto-corrige">
    <li value="1"><span class="arithmatex">\(f(5)=\)</span><wbr><span class="arithmatex">\(2\times5+3=\)</span><wbr><span class="arithmatex">\(\boxed{13}\)</span>.</li>
    <li value="2"><span class="arithmatex">\(\dfrac{11-3}{4-0}=\)</span><wbr><span class="arithmatex">\(\dfrac{8}{4}=\)</span><wbr><span class="arithmatex">\(\boxed{2}\)</span>.</li>
    <li value="3"><span class="arithmatex">\(\boxed{1{,}20}\)</span>.</li>
    <li value="4"><span class="arithmatex">\(2x=6\)</span>, donc <span class="arithmatex">\(x=\boxed{3}\)</span>.</li>
    <li value="5"><span class="arithmatex">\(6-4=2\)</span>, signe <span class="arithmatex">\(\boxed{\text{positif}}\)</span>.</li>
    <li value="6"><span class="arithmatex">\((-4)^2=\boxed{16}\)</span>.</li>
    </ol>
    <div class="auto-methode"><strong>Méthode.</strong> Remplacer, simplifier, conclure : une étape propre évite les erreurs de signe.</div>
    <div class="auto-vigilance"><strong>Vigilance.</strong> Le carré d'un nombre négatif est positif.</div>

## Série B — Paraboles : allure et sommet

<p class="auto-meta">⏱ 6 min · Calculatrice interdite</p>

<div class="auto-consigne" markdown>
**Consigne.** Reconnaître les formes simples du second degré.
</div>

<ol class="auto-questions">
<li value="1">Soit <span class="arithmatex">\(p(x)=x^2\)</span>. Calculer <span class="arithmatex">\(p(-3)\)</span>.</li>
<li value="2">Soit <span class="arithmatex">\(q(x)=-x^2\)</span>. Calculer <span class="arithmatex">\(q(2)\)</span>.</li>
<li value="3">Pour <span class="arithmatex">\(f(x)=x^2+5\)</span>, donner le sommet de la parabole.</li>
<li value="4">Pour <span class="arithmatex">\(g(x)=-2x^2+1\)</span>, la parabole est-elle ouverte vers le haut ou vers le bas ?</li>
<li value="5">Donner l'axe de symétrie de la parabole <span class="arithmatex">\(y=x^2-4\)</span>.</li>
<li value="6">Pour <span class="arithmatex">\(h(x)=x^2+3\)</span>, comparer <span class="arithmatex">\(h(-2)\)</span> et <span class="arithmatex">\(h(2)\)</span>.</li>
</ol>

??? tip "Coup de pouce"

    <p><strong>Conseils</strong></p><ul><li>Le signe de <span class="arithmatex">\(a\)</span> donne l'ouverture.</li><li>La forme <span class="arithmatex">\(x^2+c\)</span> décale verticalement.</li><li>L'axe de <span class="arithmatex">\(x^2+c\)</span> est l'axe des ordonnées.</li></ul>
    <p><strong>Vigilance</strong></p><p>Aucune formule générale du sommet n'est nécessaire ici.</p>

??? success "Corrigé de la série B"

    <ol class="auto-corrige">
    <li value="1"><span class="arithmatex">\(p(-3)=(-3)^2=\boxed{9}\)</span>.</li>
    <li value="2"><span class="arithmatex">\(q(2)=-(2^2)=\boxed{-4}\)</span>.</li>
    <li value="3">Sommet : <span class="arithmatex">\(\boxed{(0;5)}\)</span>.</li>
    <li value="4">Comme <span class="arithmatex">\(a=-2&lt;0\)</span>, elle est ouverte <span class="arithmatex">\(\boxed{\text{vers le bas}}\)</span>.</li>
    <li value="5">Axe de symétrie : <span class="arithmatex">\(\boxed{x=0}\)</span>.</li>
    <li value="6"><span class="arithmatex">\(h(-2)=7\)</span> et <span class="arithmatex">\(h(2)=7\)</span>, donc <span class="arithmatex">\(\boxed{h(-2)=h(2)}\)</span>.</li>
    </ol>
    <div class="auto-methode"><strong>Méthode.</strong> Pour <span class="arithmatex">\(a x^2+c\)</span>, le sommet est sur l'axe des ordonnées.</div>
    <div class="auto-vigilance"><strong>Vigilance.</strong> Ne pas utiliser le discriminant : il n'intervient pas dans cette notion.</div>

## Série C — Formes simples du second degré

<p class="auto-meta">⏱ 7 min · Calculatrice interdite</p>

<div class="auto-consigne" markdown>
**Consigne.** Associer expression, racines visibles et élément caractéristique.
</div>

<ol class="auto-questions">
<li value="1">Donner les racines visibles de <span class="arithmatex">\(P(x)=(x-1)(x-5)\)</span>.</li>
<li value="2">Donner les racines visibles de <span class="arithmatex">\(Q(x)=-(x+2)(x-4)\)</span>.</li>
<li value="3">Factoriser mentalement <span class="arithmatex">\(x^2-9\)</span>.</li>
<li value="4">Pour <span class="arithmatex">\(f(x)=2x^2+3\)</span>, quelle est la valeur minimale ?</li>
<li value="5">Pour <span class="arithmatex">\(g(x)=-x^2+5\)</span>, quelle est la valeur maximale ?</li>
<li value="6">Dans <span class="arithmatex">\(a(x-r_1)(x-r_2)\)</span>, quelles sont les racines visibles ?</li>
</ol>

??? tip "Coup de pouce"

    <p><strong>Conseils</strong></p><ul><li>Un produit est nul si l'un des facteurs est nul.</li><li>La forme factorisée donne les racines directement.</li><li>Une parabole ouverte vers le haut a un minimum.</li></ul>
    <p><strong>Vigilance</strong></p><p>Ne pas développer si la forme factorisée suffit.</p>

??? success "Corrigé de la série C"

    <ol class="auto-corrige">
    <li value="1"><span class="arithmatex">\(\boxed{1}\)</span> et <span class="arithmatex">\(\boxed{5}\)</span>.</li>
    <li value="2"><span class="arithmatex">\(\boxed{-2}\)</span> et <span class="arithmatex">\(\boxed{4}\)</span>.</li>
    <li value="3"><span class="arithmatex">\(x^2-9=\boxed{(x-3)(x+3)}\)</span>.</li>
    <li value="4">La valeur minimale est <span class="arithmatex">\(\boxed{3}\)</span>, atteinte pour <span class="arithmatex">\(x=0\)</span>.</li>
    <li value="5">La valeur maximale est <span class="arithmatex">\(\boxed{5}\)</span>, atteinte pour <span class="arithmatex">\(x=0\)</span>.</li>
    <li value="6">Les racines visibles sont <span class="arithmatex">\(\boxed{r_1}\)</span> et <span class="arithmatex">\(\boxed{r_2}\)</span>.</li>
    </ol>
    <div class="auto-methode"><strong>Méthode.</strong> La forme factorisée est faite pour lire les zéros.</div>
    <div class="auto-vigilance"><strong>Vigilance.</strong> Un facteur comme <span class="arithmatex">\(x+2\)</span> s'annule pour <span class="arithmatex">\(x=-2\)</span>.</div>

## Série D — QCM - second degré simple

<p class="auto-meta">⏱ 7 min · Calculatrice interdite</p>

<div class="auto-consigne" markdown>
**Consigne.** Choisir une seule réponse. Aucune justification demandée.
</div>

<ol class="auto-questions">
<li value="1">La courbe de <span class="arithmatex">\(x\mapsto -x^2+4\)</span> est :<ol class="auto-choix" type="A"><li>une droite</li><li>une parabole ouverte vers le haut</li><li>une parabole ouverte vers le bas</li><li>un point</li></ol></li>
<li value="2">Le sommet de <span class="arithmatex">\(x\mapsto x^2-6\)</span> est :<ol class="auto-choix" type="A"><li><span class="arithmatex">\((0;6)\)</span></li><li><span class="arithmatex">\((0;-6)\)</span></li><li><span class="arithmatex">\((-6;0)\)</span></li><li><span class="arithmatex">\((6;0)\)</span></li></ol></li>
<li value="3">Les racines de <span class="arithmatex">\((x-3)(x+1)\)</span> sont :<ol class="auto-choix" type="A"><li><span class="arithmatex">\(3\)</span> et <span class="arithmatex">\(1\)</span></li><li><span class="arithmatex">\(-3\)</span> et <span class="arithmatex">\(1\)</span></li><li><span class="arithmatex">\(3\)</span> et <span class="arithmatex">\(-1\)</span></li><li><span class="arithmatex">\(-3\)</span> et <span class="arithmatex">\(-1\)</span></li></ol></li>
<li value="4">Pour <span class="arithmatex">\(f(x)=x^2+2\)</span>, on a :<ol class="auto-choix" type="A"><li><span class="arithmatex">\(f(-1)=1\)</span></li><li><span class="arithmatex">\(f(-1)=3\)</span></li><li><span class="arithmatex">\(f(-1)=-3\)</span></li><li><span class="arithmatex">\(f(-1)=-1\)</span></li></ol></li>
<li value="5">L'axe de symétrie de <span class="arithmatex">\(y=-3x^2+7\)</span> est :<ol class="auto-choix" type="A"><li><span class="arithmatex">\(x=7\)</span></li><li><span class="arithmatex">\(y=7\)</span></li><li><span class="arithmatex">\(x=0\)</span></li><li><span class="arithmatex">\(y=0\)</span></li></ol></li>
<li value="6">La forme qui donne directement les racines est :<ol class="auto-choix" type="A"><li>développée</li><li>factorisée</li><li>décimale</li><li>graphique seulement</li></ol></li>
</ol>

??? tip "Coup de pouce"

    <p><strong>Conseils</strong></p><ul><li>Identifier d'abord la forme.</li><li>Le signe placé devant <span class="arithmatex">\(x^2\)</span> donne l'ouverture.</li><li>Un facteur nul donne une racine.</li></ul>
    <p><strong>Vigilance</strong></p><p>Le discriminant est hors programme : ne pas le chercher.</p>

??? success "Corrigé de la série D"

    <ol class="auto-corrige">
    <li value="1"><strong class="auto-resultat">Réponse C</strong> : Réponse : le coefficient de <span class="arithmatex">\(x^2\)</span> est négatif.</li>
    <li value="2"><strong class="auto-resultat">Réponse B</strong> : Réponse : sommet <span class="arithmatex">\((0;-6)\)</span>.</li>
    <li value="3"><strong class="auto-resultat">Réponse C</strong> : Réponse : <span class="arithmatex">\(x=3\)</span> ou <span class="arithmatex">\(x=-1\)</span>.</li>
    <li value="4"><strong class="auto-resultat">Réponse B</strong> : Réponse : <span class="arithmatex">\((-1)^2+2=3\)</span>.</li>
    <li value="5"><strong class="auto-resultat">Réponse C</strong> : Réponse : axe <span class="arithmatex">\(x=0\)</span>.</li>
    <li value="6"><strong class="auto-resultat">Réponse B</strong> : Réponse : la forme factorisée.</li>
    </ol>
    <div class="auto-methode"><strong>Méthode.</strong> Lire ce que la forme donne directement : sommet, ouverture ou racines.</div>
    <div class="auto-vigilance"><strong>Vigilance.</strong> Ne pas développer si la réponse est lisible sans calcul long.</div>
