## Série A — Choisir et calculer un modèle

<p class="auto-meta">⏱ 6 min · Calculatrice interdite</p>

<div class="auto-consigne" markdown>
**Consigne.** Réactiver rapidement fonctions, suites et interprétation en gestion.
</div>

<ol class="auto-questions">
<li value="1">Un coût est <span class="arithmatex">\(C(q)=2q+40\)</span> et une recette <span class="arithmatex">\(R(q)=6q\)</span>. Donner le bénéfice <span class="arithmatex">\(B(q)\)</span>.</li>
<li value="2">Avec <span class="arithmatex">\(B(q)=4q-40\)</span>, résoudre mentalement <span class="arithmatex">\(B(q)&gt;0\)</span>.</li>
<li value="3">Une fréquentation passe de <span class="arithmatex">\(200\)</span> à <span class="arithmatex">\(210\)</span>. Donner le taux d'évolution.</li>
<li value="4">Une suite vérifie <span class="arithmatex">\(u(0)=200\)</span> et <span class="arithmatex">\(u(n+1)=1{,}05u(n)\)</span>. Calculer <span class="arithmatex">\(u(1)\)</span>.</li>
<li value="5">Pour un relevé tous les lundis, choisir le modèle : fonction continue ou suite ?</li>
<li value="6">Le prix dépend de toute valeur réelle <span class="arithmatex">\(x\)</span> entre <span class="arithmatex">\(0\)</span> et <span class="arithmatex">\(10\)</span>. Choisir : tableau discret ou fonction ?</li>
</ol>

??? tip "Coup de pouce"

    <p><strong>Conseils</strong></p><ul><li>Identifier coût, recette et bénéfice.</li><li>Un bénéfice positif signifie recette supérieure au coût.</li><li>Discret : valeurs par rang ; continu : valeurs intermédiaires possibles.</li></ul>
    <p><strong>Vigilance</strong></p><p>Ne pas appliquer une formule avant d'avoir choisi le bon registre.</p>

??? success "Corrigé de la série A"

    <ol class="auto-corrige">
    <li value="1"><span class="arithmatex">\(B(q)=\)</span><wbr><span class="arithmatex">\(R(q)-C(q)=\)</span><wbr><span class="arithmatex">\(6q-(2q+40)=\)</span><wbr><span class="arithmatex">\(\boxed{4q-40}\)</span>.</li>
    <li value="2"><span class="arithmatex">\(4q-40&gt;0\Longleftrightarrow\)</span><wbr><span class="arithmatex">\( q&gt;10\)</span>. Donc <span class="arithmatex">\(\boxed{q&gt;10}\)</span>.</li>
    <li value="3"><span class="arithmatex">\(\frac{210-200}{200}=\)</span><wbr><span class="arithmatex">\(0{,}05\)</span>, soit <span class="arithmatex">\(\boxed{5\,\%}\)</span>.</li>
    <li value="4"><span class="arithmatex">\(u(1)=\)</span><wbr><span class="arithmatex">\(1{,}05\times200=\)</span><wbr><span class="arithmatex">\(\boxed{210}\)</span>.</li>
    <li value="5">Relevé hebdomadaire : <strong class="auto-resultat">suite</strong>.</li>
    <li value="6">Valeurs réelles possibles : <strong class="auto-resultat">fonction</strong>.</li>
    </ol>
    <div class="auto-methode"><strong>Méthode.</strong> Avant de calculer, décider si la situation est discrète, continue, algébrique ou graphique.</div>
    <div class="auto-vigilance"><strong>Vigilance.</strong> L'interprétation finale fait partie de la réponse attendue.</div>

## Série B — Dériver pour optimiser

<p class="auto-meta">⏱ 6 min · Calculatrice interdite</p>

<div class="auto-consigne" markdown>
**Consigne.** Calculer une dérivée simple et lire le sens de variation utile.
</div>

<ol class="auto-questions">
<li value="1">Pour <span class="arithmatex">\(f(x)=-x^2+12x-20\)</span>, calculer <span class="arithmatex">\(f'(x)\)</span>.</li>
<li value="2">Résoudre mentalement <span class="arithmatex">\(-2x+12=0\)</span>.</li>
<li value="3">Donner le signe de <span class="arithmatex">\(-2x+12\)</span> pour <span class="arithmatex">\(x&lt;6\)</span>.</li>
<li value="4">Sur <span class="arithmatex">\([0;10]\)</span>, <span class="arithmatex">\(f\)</span> est-elle croissante avant <span class="arithmatex">\(6\)</span> ou après <span class="arithmatex">\(6\)</span> ?</li>
<li value="5">Calculer <span class="arithmatex">\(f(6)\)</span>.</li>
<li value="6">Si <span class="arithmatex">\(f\)</span> est un bénéfice en centaines d'euros, que représente le maximum ?</li>
</ol>

??? tip "Coup de pouce"

    <p><strong>Conseils</strong></p><ul><li>Dérivée de <span class="arithmatex">\(x^2\)</span> : <span class="arithmatex">\(2x\)</span>.</li><li>Le signe de la dérivée donne les variations.</li><li>Un maximum de bénéfice est une quantité optimale.</li></ul>
    <p><strong>Vigilance</strong></p><p>Ne pas confondre l'abscisse du maximum et la valeur maximale.</p>

??? success "Corrigé de la série B"

    <ol class="auto-corrige">
    <li value="1"><span class="arithmatex">\(f'(x)=\boxed{-2x+12}\)</span>.</li>
    <li value="2"><span class="arithmatex">\(-2x+12=0\Longleftrightarrow\)</span><wbr><span class="arithmatex">\( x=\boxed{6}\)</span>.</li>
    <li value="3">Pour <span class="arithmatex">\(x&lt;6\)</span>, <span class="arithmatex">\(-2x+12&gt;0\)</span>, donc le signe est <span class="arithmatex">\(\boxed{+}\)</span>.</li>
    <li value="4">La fonction est <strong class="auto-resultat">croissante avant <span class="arithmatex">\(6\)</span></strong>.</li>
    <li value="5"><span class="arithmatex">\(f(6)=\)</span><wbr><span class="arithmatex">\(-36+72-20=\)</span><wbr><span class="arithmatex">\(\boxed{16}\)</span>.</li>
    <li value="6">Le maximum est <strong class="auto-resultat">le bénéfice le plus élevé possible</strong>.</li>
    </ol>
    <div class="auto-methode"><strong>Méthode.</strong> Dérivée positive : fonction croissante. Dérivée négative : fonction décroissante.</div>
    <div class="auto-vigilance"><strong>Vigilance.</strong> Ici <span class="arithmatex">\(6\)</span> est la quantité optimale ; <span class="arithmatex">\(16\)</span> est le bénéfice maximal en centaines d'euros.</div>

## Série C — Passer d'un registre à l'autre

<p class="auto-meta">⏱ 6 min · Calculatrice interdite</p>

<div class="auto-consigne" markdown>
**Consigne.** Lire une information dans un tableau puis la traduire.
</div>

<ol class="auto-questions">
<li value="1"><span class="arithmatex">\(\begin{array}{c|ccc} q&amp;0&amp;5&amp;10\\ \hline B(q)&amp;-40&amp;-20&amp;0\end{array}\)</span> Calculer le taux de variation entre <span class="arithmatex">\(0\)</span> et <span class="arithmatex">\(5\)</span>.</li>
<li value="2">Avec le même tableau, calculer le taux de variation entre <span class="arithmatex">\(5\)</span> et <span class="arithmatex">\(10\)</span>.</li>
<li value="3">Le bénéfice augmente-t-il de façon régulière sur ces deux intervalles ?</li>
<li value="4">Si <span class="arithmatex">\(B(q)=4q-40\)</span>, calculer <span class="arithmatex">\(B(12)\)</span>.</li>
<li value="5">Résoudre <span class="arithmatex">\(4q-40=0\)</span>.</li>
<li value="6">Interpréter <span class="arithmatex">\(q=10\)</span> dans le contexte du bénéfice.</li>
</ol>

??? tip "Coup de pouce"

    <p><strong>Conseils</strong></p><ul><li>Taux de variation : <span class="arithmatex">\(\frac{\Delta y}{\Delta x}\)</span>.</li><li>Comparer deux taux de variation permet de repérer une régularité.</li><li>L'équation <span class="arithmatex">\(B(q)=0\)</span> correspond au seuil de rentabilité.</li></ul>
    <p><strong>Vigilance</strong></p><p>Un taux de variation n'est pas un pourcentage d'évolution.</p>

??? success "Corrigé de la série C"

    <ol class="auto-corrige">
    <li value="1"><span class="arithmatex">\(\frac{-20-(-40)}{5-0}=\)</span><wbr><span class="arithmatex">\(\frac{20}{5}=\)</span><wbr><span class="arithmatex">\(\boxed{4}\)</span>.</li>
    <li value="2"><span class="arithmatex">\(\frac{0-(-20)}{10-5}=\)</span><wbr><span class="arithmatex">\(\frac{20}{5}=\)</span><wbr><span class="arithmatex">\(\boxed{4}\)</span>.</li>
    <li value="3">Oui, le taux est constant : <strong class="auto-resultat">augmentation régulière</strong>.</li>
    <li value="4"><span class="arithmatex">\(B(12)=\)</span><wbr><span class="arithmatex">\(4\times12-40=\)</span><wbr><span class="arithmatex">\(\boxed{8}\)</span>.</li>
    <li value="5"><span class="arithmatex">\(4q-40=0\Longleftrightarrow\)</span><wbr><span class="arithmatex">\( q=\boxed{10}\)</span>.</li>
    <li value="6"><span class="arithmatex">\(q=10\)</span> est <strong class="auto-resultat">le seuil de rentabilité</strong>.</li>
    </ol>
    <div class="auto-methode"><strong>Méthode.</strong> Le seuil de rentabilité est la valeur pour laquelle le bénéfice est nul.</div>
    <div class="auto-vigilance"><strong>Vigilance.</strong> Une conclusion doit préciser l'unité ou le sens économique.</div>

## Série D — QCM cumulatif type épreuve

<p class="auto-meta">⏱ 6 min · Calculatrice interdite</p>

<div class="auto-consigne" markdown>
**Consigne.** Choisir une seule réponse. Aucune justification demandée.
</div>

<ol class="auto-questions">
<li value="1">Si <span class="arithmatex">\(u(n)=150\times1{,}02^n\)</span>, alors <span class="arithmatex">\(u(1)=\)</span><ol class="auto-choix" type="A"><li><span class="arithmatex">\(152\)</span></li><li><span class="arithmatex">\(153\)</span></li><li><span class="arithmatex">\(150{,}02\)</span></li><li><span class="arithmatex">\(147\)</span></li></ol></li>
<li value="2">La dérivée de <span class="arithmatex">\(3x^2-5x+1\)</span> est<ol class="auto-choix" type="A"><li><span class="arithmatex">\(6x-5\)</span></li><li><span class="arithmatex">\(3x-5\)</span></li><li><span class="arithmatex">\(6x+1\)</span></li><li><span class="arithmatex">\(x^3-5\)</span></li></ol></li>
<li value="3">Si <span class="arithmatex">\(f'(x)&lt;0\)</span> sur un intervalle, alors <span class="arithmatex">\(f\)</span> est<ol class="auto-choix" type="A"><li>croissante</li><li>décroissante</li><li>positive</li><li>nulle</li></ol></li>
<li value="4">Un bénéfice nul correspond à<ol class="auto-choix" type="A"><li>un maximum</li><li>une dérivée</li><li>un seuil de rentabilité</li><li>une moyenne</li></ol></li>
<li value="5">Le modèle adapté à des mois <span class="arithmatex">\(n=0;1;2;\ldots\)</span> est plutôt<ol class="auto-choix" type="A"><li>une suite</li><li>un disque</li><li>une racine</li><li>une aire</li></ol></li>
</ol>

??? tip "Coup de pouce"

    <p><strong>Conseils</strong></p><ul><li>Éliminer les réponses incompatibles avec la nature de l'objet.</li><li>Repérer les mots clés : dérivée, bénéfice nul, rang.</li><li>Une seule réponse est correcte.</li></ul>
    <p><strong>Vigilance</strong></p><p>Une réponse rapide doit rester vérifiée mentalement.</p>

??? success "Corrigé de la série D"

    <ol class="auto-corrige">
    <li value="1"><strong class="auto-resultat">Réponse B</strong> : Réponse : <span class="arithmatex">\(150\times1{,}02=\)</span><wbr><span class="arithmatex">\(\boxed{153}\)</span>.</li>
    <li value="2"><strong class="auto-resultat">Réponse A</strong> : Réponse : <span class="arithmatex">\(\boxed{6x-5}\)</span>.</li>
    <li value="3"><strong class="auto-resultat">Réponse B</strong> : Réponse : dérivée négative donc décroissante.</li>
    <li value="4"><strong class="auto-resultat">Réponse C</strong> : Réponse : bénéfice nul = seuil de rentabilité.</li>
    <li value="5"><strong class="auto-resultat">Réponse A</strong> : Réponse : un rang entier correspond à une suite.</li>
    </ol>
    <div class="auto-methode"><strong>Méthode.</strong> En QCM, calculer juste assez pour choisir, puis vérifier l'ordre de grandeur.</div>
    <div class="auto-vigilance"><strong>Vigilance.</strong> Pour la question 1, <span class="arithmatex">\(2\,\%\)</span> de <span class="arithmatex">\(150\)</span> vaut <span class="arithmatex">\(3\)</span>, donc <span class="arithmatex">\(153\)</span>.</div>
