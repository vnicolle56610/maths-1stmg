## Série A — Dérivées de base

<p class="auto-meta">⏱ 6 min · Calculatrice interdite</p>

<div class="auto-consigne" markdown>
**Consigne.** Calculer les dérivées de fonctions simples.
</div>

<ol class="auto-questions">
<li value="1">Si <span class="arithmatex">\(f(x)=x^2\)</span>, donner <span class="arithmatex">\(f'(x)\)</span>.</li>
<li value="2">Si <span class="arithmatex">\(g(x)=x^3\)</span>, donner <span class="arithmatex">\(g'(x)\)</span>.</li>
<li value="3">Si <span class="arithmatex">\(h(x)=7\)</span>, donner <span class="arithmatex">\(h'(x)\)</span>.</li>
<li value="4">Si <span class="arithmatex">\(p(x)=5x\)</span>, donner <span class="arithmatex">\(p'(x)\)</span>.</li>
<li value="5">Si <span class="arithmatex">\(q(x)=3x^2\)</span>, donner <span class="arithmatex">\(q'(x)\)</span>.</li>
<li value="6">Si <span class="arithmatex">\(r(x)=-2x^3\)</span>, donner <span class="arithmatex">\(r'(x)\)</span>.</li>
</ol>

??? tip "Coup de pouce"

    <p><strong>Conseils</strong></p><ul><li>Mémoriser : <span class="arithmatex">\((x^2)'=2x\)</span> et <span class="arithmatex">\((x^3)'=3x^2\)</span>.</li><li>Une constante a une dérivée nulle.</li><li>Le coefficient multiplicatif reste devant.</li></ul>
    <p><strong>Vigilance</strong></p><p>La dérivée de <span class="arithmatex">\(x^3\)</span> n'est pas <span class="arithmatex">\(3x\)</span>, mais <span class="arithmatex">\(3x^2\)</span>.</p>

??? success "Corrigé de la série A"

    <ol class="auto-corrige">
    <li value="1"><span class="arithmatex">\(\boxed{f'(x)=2x}\)</span>.</li>
    <li value="2"><span class="arithmatex">\(\boxed{g'(x)=3x^2}\)</span>.</li>
    <li value="3"><span class="arithmatex">\(\boxed{h'(x)=0}\)</span>.</li>
    <li value="4"><span class="arithmatex">\(\boxed{p'(x)=5}\)</span>.</li>
    <li value="5"><span class="arithmatex">\(\boxed{q'(x)=6x}\)</span>.</li>
    <li value="6"><span class="arithmatex">\(\boxed{r'(x)=-6x^2}\)</span>.</li>
    </ol>
    <div class="auto-methode"><strong>Méthode.</strong> On dérive terme par terme en gardant les coefficients.</div>
    <div class="auto-vigilance"><strong>Vigilance.</strong> Une fonction constante a une courbe horizontale : pente nulle.</div>

## Série B — Linéarité

<p class="auto-meta">⏱ 6 min · Calculatrice interdite</p>

<div class="auto-consigne" markdown>
**Consigne.** Dériver une somme de termes.
</div>

<ol class="auto-questions">
<li value="1">Dériver <span class="arithmatex">\(f(x)=x^2+3x+4\)</span>.</li>
<li value="2">Dériver <span class="arithmatex">\(g(x)=2x^2-5x+1\)</span>.</li>
<li value="3">Dériver <span class="arithmatex">\(h(x)=x^3+x^2\)</span>.</li>
<li value="4">Dériver <span class="arithmatex">\(p(x)=4x^3-2x^2+7\)</span>.</li>
<li value="5">Dériver <span class="arithmatex">\(q(x)=-x^3+6x\)</span>.</li>
<li value="6">Dériver <span class="arithmatex">\(r(x)=3x^2+8\)</span>.</li>
</ol>

??? tip "Coup de pouce"

    <p><strong>Conseils</strong></p><ul><li>Dériver chaque terme séparément.</li><li>Une constante disparaît.</li><li>Réduire ensuite si possible.</li></ul>
    <p><strong>Vigilance</strong></p><p>Le signe du terme reste important pendant la dérivation.</p>

??? success "Corrigé de la série B"

    <ol class="auto-corrige">
    <li value="1"><span class="arithmatex">\(\boxed{f'(x)=2x+3}\)</span>.</li>
    <li value="2"><span class="arithmatex">\(\boxed{g'(x)=4x-5}\)</span>.</li>
    <li value="3"><span class="arithmatex">\(\boxed{h'(x)=3x^2+2x}\)</span>.</li>
    <li value="4"><span class="arithmatex">\(\boxed{p'(x)=12x^2-4x}\)</span>.</li>
    <li value="5"><span class="arithmatex">\(\boxed{q'(x)=-3x^2+6}\)</span>.</li>
    <li value="6"><span class="arithmatex">\(\boxed{r'(x)=6x}\)</span>.</li>
    </ol>
    <div class="auto-methode"><strong>Méthode.</strong> La dérivée d'une somme est la somme des dérivées.</div>
    <div class="auto-vigilance"><strong>Vigilance.</strong> Ne pas dériver le nombre <span class="arithmatex">\(+4\)</span>, <span class="arithmatex">\(+1\)</span> ou <span class="arithmatex">\(+8\)</span> en <span class="arithmatex">\(1\)</span>.</div>

## Série C — Tangente : équation réduite

<p class="auto-meta">⏱ 7 min · Calculatrice interdite</p>

<div class="auto-consigne" markdown>
**Consigne.** Utiliser <span class="arithmatex">\(f'(a)\)</span> pour écrire une tangente.
</div>

<ol class="auto-questions">
<li value="1">Si <span class="arithmatex">\(f(2)=5\)</span> et <span class="arithmatex">\(f'(2)=3\)</span>, la tangente passe par quel point ?</li>
<li value="2">Avec <span class="arithmatex">\(f(2)=5\)</span> et <span class="arithmatex">\(f'(2)=3\)</span>, son coefficient directeur vaut combien ?</li>
<li value="3">Compléter : <span class="arithmatex">\(y=f'(a)(x-a)+f(a)\)</span>. Pour <span class="arithmatex">\(a=2\)</span>, <span class="arithmatex">\(f(a)=5\)</span>, <span class="arithmatex">\(f'(a)=3\)</span>.</li>
<li value="4">Pour <span class="arithmatex">\(f(x)=x^2\)</span>, calculer <span class="arithmatex">\(f'(3)\)</span>.</li>
<li value="5">Pour <span class="arithmatex">\(f(x)=x^2\)</span>, calculer <span class="arithmatex">\(f(3)\)</span>.</li>
<li value="6">Écrire l'équation de la tangente à <span class="arithmatex">\(f(x)=x^2\)</span> en <span class="arithmatex">\(x=3\)</span>.</li>
</ol>

??? tip "Coup de pouce"

    <p><strong>Conseils</strong></p><ul><li>Point de contact : <span class="arithmatex">\((a;f(a))\)</span>.</li><li>Pente de la tangente : <span class="arithmatex">\(f'(a)\)</span>.</li><li>Formule utile : <span class="arithmatex">\(y=f'(a)(x-a)+f(a)\)</span>.</li></ul>
    <p><strong>Vigilance</strong></p><p>Il faut deux informations : un point et une pente.</p>

??? success "Corrigé de la série C"

    <ol class="auto-corrige">
    <li value="1">Elle passe par <span class="arithmatex">\(\boxed{(2;5)}\)</span>.</li>
    <li value="2">Le coefficient directeur vaut <span class="arithmatex">\(\boxed{3}\)</span>.</li>
    <li value="3"><span class="arithmatex">\(\boxed{y=3(x-2)+5}\)</span>.</li>
    <li value="4"><span class="arithmatex">\(f'(x)=2x\)</span>, donc <span class="arithmatex">\(f'(3)=\boxed{6}\)</span>.</li>
    <li value="5"><span class="arithmatex">\(f(3)=\boxed{9}\)</span>.</li>
    <li value="6"><span class="arithmatex">\(\boxed{y=6(x-3)+9}\)</span>, soit <span class="arithmatex">\(y=6x-9\)</span>.</li>
    </ol>
    <div class="auto-methode"><strong>Méthode.</strong> Pour une tangente, on remplace <span class="arithmatex">\(a\)</span> par l'abscisse du point de contact.</div>
    <div class="auto-vigilance"><strong>Vigilance.</strong> Ne pas confondre <span class="arithmatex">\(f(a)\)</span>, l'ordonnée, avec <span class="arithmatex">\(f'(a)\)</span>, la pente.</div>

## Série D — QCM : dériver vite

<p class="auto-meta">⏱ 7 min · Calculatrice interdite</p>

<div class="auto-consigne" markdown>
**Consigne.** Choisir la bonne réponse.
</div>

<ol class="auto-questions">
<li value="1">La dérivée de <span class="arithmatex">\(x^2+5\)</span> est<ol class="auto-choix" type="A"><li><span class="arithmatex">\(2x+5\)</span></li><li><span class="arithmatex">\(2x\)</span></li><li><span class="arithmatex">\(x\)</span></li><li><span class="arithmatex">\(2\)</span></li></ol></li>
<li value="2">La dérivée de <span class="arithmatex">\(3x^3\)</span> est<ol class="auto-choix" type="A"><li><span class="arithmatex">\(3x^2\)</span></li><li><span class="arithmatex">\(9x^2\)</span></li><li><span class="arithmatex">\(9x\)</span></li><li><span class="arithmatex">\(x^2\)</span></li></ol></li>
<li value="3">La dérivée de <span class="arithmatex">\(4x-7\)</span> est<ol class="auto-choix" type="A"><li><span class="arithmatex">\(4x\)</span></li><li><span class="arithmatex">\(4\)</span></li><li><span class="arithmatex">\(-7\)</span></li><li><span class="arithmatex">\(0\)</span></li></ol></li>
<li value="4">Si <span class="arithmatex">\(f'(2)=0\)</span>, la tangente en <span class="arithmatex">\(x=2\)</span> est<ol class="auto-choix" type="A"><li>verticale</li><li>horizontale</li><li>croissante</li><li>absente</li></ol></li>
<li value="5">Pour <span class="arithmatex">\(f(x)=x^2+1\)</span>, <span class="arithmatex">\(f'(2)=\)</span><ol class="auto-choix" type="A"><li><span class="arithmatex">\(2\)</span></li><li><span class="arithmatex">\(4\)</span></li><li><span class="arithmatex">\(5\)</span></li><li><span class="arithmatex">\(0\)</span></li></ol></li>
<li value="6">Dans <span class="arithmatex">\(y=f'(a)(x-a)+f(a)\)</span>, <span class="arithmatex">\(f'(a)\)</span> est<ol class="auto-choix" type="A"><li>une ordonnée</li><li>une pente</li><li>une abscisse</li><li>un intervalle</li></ol></li>
</ol>

??? tip "Coup de pouce"

    <p><strong>Conseils</strong></p><ul><li>Dériver terme par terme.</li><li>La constante disparaît.</li><li>Pour une tangente, repérer pente et point.</li></ul>
    <p><strong>Vigilance</strong></p><p>La dérivée est une fonction : on peut ensuite l'évaluer en un nombre.</p>

??? success "Corrigé de la série D"

    <ol class="auto-corrige">
    <li value="1"><strong class="auto-resultat">Réponse B</strong> : <span class="arithmatex">\(2x\)</span></li>
    <li value="2"><strong class="auto-resultat">Réponse B</strong> : <span class="arithmatex">\(9x^2\)</span></li>
    <li value="3"><strong class="auto-resultat">Réponse B</strong> : <span class="arithmatex">\(4\)</span></li>
    <li value="4"><strong class="auto-resultat">Réponse B</strong> : horizontale</li>
    <li value="5"><strong class="auto-resultat">Réponse B</strong> : <span class="arithmatex">\(f'(x)=2x\)</span>.</li>
    <li value="6"><strong class="auto-resultat">Réponse B</strong> : une pente</li>
    </ol>
    <div class="auto-methode"><strong>Méthode.</strong> Les dérivées de polynômes de degré au plus <span class="arithmatex">\(3\)</span> doivent devenir automatiques.</div>
    <div class="auto-vigilance"><strong>Vigilance.</strong> Une erreur fréquente consiste à oublier le carré dans <span class="arithmatex">\((x^3)'=3x^2\)</span>.</div>
