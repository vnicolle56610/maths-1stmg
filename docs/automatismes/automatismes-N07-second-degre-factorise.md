## Série A — Racines et produit nul

<p class="auto-meta">⏱ 6 min · Calculatrice interdite</p>

<div class="auto-consigne" markdown>
**Consigne.** Résoudre mentalement des équations produit nul.
</div>

<ol class="auto-questions">
<li value="1">Résoudre <span class="arithmatex">\((x-2)(x+5)=0\)</span>.</li>
<li value="2">Donner les racines de <span class="arithmatex">\(3(x-1)(x-4)\)</span>.</li>
<li value="3">Quel est le signe de <span class="arithmatex">\(x-3\)</span> pour <span class="arithmatex">\(x=5\)</span> ?</li>
<li value="4">Quel est le signe de <span class="arithmatex">\((x-1)(x-4)\)</span> pour <span class="arithmatex">\(x=0\)</span> ?</li>
<li value="5">Quel est le signe de <span class="arithmatex">\((x-1)(x-4)\)</span> pour <span class="arithmatex">\(x=2\)</span> ?</li>
<li value="6">Quel est le signe de <span class="arithmatex">\((x-1)(x-4)\)</span> pour <span class="arithmatex">\(x=5\)</span> ?</li>
</ol>

??? tip "Coup de pouce"

    <p><strong>Conseils</strong></p><ul><li>Produit nul : un facteur nul suffit.</li><li>Pour un signe, tester une valeur simple.</li><li>Attention aux facteurs <span class="arithmatex">\(x+a\)</span>.</li></ul>
    <p><strong>Vigilance</strong></p><p>Ne pas inverser la racine de <span class="arithmatex">\(x+5\)</span> : elle vaut <span class="arithmatex">\(-5\)</span>.</p>

??? success "Corrigé de la série A"

    <ol class="auto-corrige">
    <li value="1"><span class="arithmatex">\(\mathscr S=\)</span><wbr><span class="arithmatex">\(\boxed{\{-5\,;\,2\}}\)</span>.</li>
    <li value="2">Les racines sont <span class="arithmatex">\(\boxed{1}\)</span> et <span class="arithmatex">\(\boxed{4}\)</span>.</li>
    <li value="3"><span class="arithmatex">\(5-3=2\)</span>, signe <span class="arithmatex">\(\boxed{\text{positif}}\)</span>.</li>
    <li value="4"><span class="arithmatex">\((-1)(-4)=4\)</span>, signe <span class="arithmatex">\(\boxed{\text{positif}}\)</span>.</li>
    <li value="5"><span class="arithmatex">\((1)(-2)=-2\)</span>, signe <span class="arithmatex">\(\boxed{\text{négatif}}\)</span>.</li>
    <li value="6"><span class="arithmatex">\((4)(1)=4\)</span>, signe <span class="arithmatex">\(\boxed{\text{positif}}\)</span>.</li>
    </ol>
    <div class="auto-methode"><strong>Méthode.</strong> Pour une forme factorisée, les racines et le signe se lisent par facteurs.</div>
    <div class="auto-vigilance"><strong>Vigilance.</strong> Tester une valeur ne remplace pas une étude complète, mais aide à construire le signe.</div>

## Série B — Signe d'une forme factorisée

<p class="auto-meta">⏱ 7 min · Calculatrice interdite</p>

<div class="auto-consigne" markdown>
**Consigne.** Lire les racines puis le signe d'un polynôme factorisé.
</div>

<ol class="auto-questions">
<li value="1">Donner les racines de <span class="arithmatex">\(P(x)=-2(x+3)(x-1)\)</span>.</li>
<li value="2">Quel est le signe de <span class="arithmatex">\(P(x)\)</span> sur <span class="arithmatex">\(]-3;1[\)</span> ?</li>
<li value="3">Pour <span class="arithmatex">\(Q(x)=(x-2)(x-6)\)</span>, résoudre <span class="arithmatex">\(Q(x)&gt;0\)</span>.</li>
<li value="4">Pour <span class="arithmatex">\(Q(x)=(x-2)(x-6)\)</span>, résoudre <span class="arithmatex">\(Q(x)&lt;0\)</span>.</li>
<li value="5">Pour <span class="arithmatex">\(Q(x)=(x-2)(x-6)\)</span>, que valent <span class="arithmatex">\(Q(2)\)</span> et <span class="arithmatex">\(Q(6)\)</span> ?</li>
<li value="6">Un bénéfice est <span class="arithmatex">\(B(q)=(q-2)(6-q)\)</span>. Pour quelles quantités <span class="arithmatex">\(B(q)&gt;0\)</span> ?</li>
</ol>

??? tip "Coup de pouce"

    <p><strong>Conseils</strong></p><ul><li>Repérer d'abord les racines.</li><li>Tester un intervalle.</li><li>Conclure en contexte.</li></ul>
    <p><strong>Vigilance</strong></p><p>Le coefficient devant les facteurs compte.</p>

??? success "Corrigé de la série B"

    <ol class="auto-corrige">
    <li value="1">Racines : <span class="arithmatex">\(\boxed{-3}\)</span> et <span class="arithmatex">\(\boxed{1}\)</span>.</li>
    <li value="2">Entre les racines : <span class="arithmatex">\((x+3)&gt;0\)</span>, <span class="arithmatex">\((x-1)&lt;0\)</span>, puis <span class="arithmatex">\(-2\)</span> rend <span class="arithmatex">\(P(x)\)</span> <span class="arithmatex">\(\boxed{\text{positif}}\)</span>.</li>
    <li value="3"><span class="arithmatex">\(\mathscr S=\)</span><wbr><span class="arithmatex">\(\boxed{]-\infty;2[\cup]6;+\infty[}\)</span>.</li>
    <li value="4"><span class="arithmatex">\(\mathscr S=\boxed{]2;6[}\)</span>.</li>
    <li value="5"><span class="arithmatex">\(Q(2)=\boxed{0}\)</span> et <span class="arithmatex">\(Q(6)=\boxed{0}\)</span>.</li>
    <li value="6"><span class="arithmatex">\(B(q)&gt;0\)</span> pour <span class="arithmatex">\(\boxed{2&lt;q&lt;6}\)</span>.</li>
    </ol>
    <div class="auto-methode"><strong>Méthode.</strong> Lire les racines, découper la droite, puis déterminer le signe sur chaque intervalle.</div>
    <div class="auto-vigilance"><strong>Vigilance.</strong> Dans un problème, les bornes où le bénéfice est nul ne sont pas des bénéfices positifs.</div>

## Série C — Vérifier et factoriser dans des cas simples

<p class="auto-meta">⏱ 7 min · Calculatrice interdite</p>

<div class="auto-consigne" markdown>
**Consigne.** Utiliser une racine connue pour factoriser ou conclure.
</div>

<ol class="auto-questions">
<li value="1">Vérifier que <span class="arithmatex">\(2\)</span> est racine de <span class="arithmatex">\(P(x)=x^2-5x+6\)</span>.</li>
<li value="2">Si les racines de <span class="arithmatex">\(P\)</span> sont <span class="arithmatex">\(2\)</span> et <span class="arithmatex">\(3\)</span> et le coefficient dominant vaut <span class="arithmatex">\(1\)</span>, écrire <span class="arithmatex">\(P(x)\)</span> sous forme factorisée.</li>
<li value="3">Factoriser <span class="arithmatex">\(x^2-4x\)</span>.</li>
<li value="4">Donner les racines de <span class="arithmatex">\(x(x-4)\)</span>.</li>
<li value="5">Résoudre <span class="arithmatex">\(x(x-4)\geqslant 0\)</span>.</li>
<li value="6">Quelle méthode est interdite ici pour chercher les racines ?</li>
</ol>

??? tip "Coup de pouce"

    <p><strong>Conseils</strong></p><ul><li>Vérifier : remplacer <span class="arithmatex">\(x\)</span>.</li><li>Factoriser si c'est visible.</li><li>Lire le signe par intervalles.</li></ul>
    <p><strong>Vigilance</strong></p><p>Pas de recherche systématique par formule.</p>

??? success "Corrigé de la série C"

    <ol class="auto-corrige">
    <li value="1"><span class="arithmatex">\(P(2)=4-10+6=\boxed{0}\)</span>, donc <span class="arithmatex">\(2\)</span> est racine.</li>
    <li value="2"><span class="arithmatex">\(P(x)=\boxed{(x-2)(x-3)}\)</span>.</li>
    <li value="3"><span class="arithmatex">\(x^2-4x=\boxed{x(x-4)}\)</span>.</li>
    <li value="4">Racines : <span class="arithmatex">\(\boxed{0}\)</span> et <span class="arithmatex">\(\boxed{4}\)</span>.</li>
    <li value="5"><span class="arithmatex">\(\mathscr S=\)</span><wbr><span class="arithmatex">\(\boxed{]-\infty;0]\cup[4;+\infty[}\)</span>.</li>
    <li value="6"><span class="arithmatex">\(\boxed{\text{Le discriminant}}\)</span> n'est pas une méthode du programme.</li>
    </ol>
    <div class="auto-methode"><strong>Méthode.</strong> Quand une racine est connue, on exploite une factorisation simple ou visible.</div>
    <div class="auto-vigilance"><strong>Vigilance.</strong> Le discriminant ne doit pas être introduit en Première STMG.</div>

## Série D — QCM - second degré factorisé

<p class="auto-meta">⏱ 7 min · Calculatrice interdite</p>

<div class="auto-consigne" markdown>
**Consigne.** Choisir une seule réponse. Aucune justification demandée.
</div>

<ol class="auto-questions">
<li value="1">Les racines de <span class="arithmatex">\(2(x+1)(x-5)\)</span> sont :<ol class="auto-choix" type="A"><li><span class="arithmatex">\(1\)</span> et <span class="arithmatex">\(5\)</span></li><li><span class="arithmatex">\(-1\)</span> et <span class="arithmatex">\(5\)</span></li><li><span class="arithmatex">\(-1\)</span> et <span class="arithmatex">\(-5\)</span></li><li><span class="arithmatex">\(2\)</span> et <span class="arithmatex">\(5\)</span></li></ol></li>
<li value="2">Pour <span class="arithmatex">\(P(x)=(x-3)(x-7)\)</span>, <span class="arithmatex">\(P(5)\)</span> est :<ol class="auto-choix" type="A"><li>positif</li><li>négatif</li><li>nul</li><li>impossible</li></ol></li>
<li value="3"><span class="arithmatex">\((x+4)(x-2)=0\)</span> a pour ensemble solution :<ol class="auto-choix" type="A"><li><span class="arithmatex">\(\{-4;2\}\)</span></li><li><span class="arithmatex">\(\{4;2\}\)</span></li><li><span class="arithmatex">\(\{-4;-2\}\)</span></li><li><span class="arithmatex">\(\{0;2\}\)</span></li></ol></li>
<li value="4">Si <span class="arithmatex">\(B(q)&gt;0\)</span> pour <span class="arithmatex">\(3&lt;q&lt;9\)</span>, le bénéfice est positif :<ol class="auto-choix" type="A"><li>aux bornes</li><li>entre les bornes</li><li>partout</li><li>jamais</li></ol></li>
<li value="5">La forme <span class="arithmatex">\(-3(x-1)(x+6)\)</span> possède :<ol class="auto-choix" type="A"><li>aucune racine</li><li>une racine</li><li>deux racines visibles</li><li>trois racines</li></ol></li>
<li value="6">Pour trouver le signe, on doit d'abord repérer :<ol class="auto-choix" type="A"><li>les unités</li><li>les racines</li><li>le nombre de questions</li><li>le discriminant</li></ol></li>
</ol>

??? tip "Coup de pouce"

    <p><strong>Conseils</strong></p><ul><li>Traiter chaque facteur séparément.</li><li>Entre deux racines, tester une valeur simple.</li><li>Une seule réponse est correcte.</li></ul>
    <p><strong>Vigilance</strong></p><p>Ne pas choisir une méthode hors programme.</p>

??? success "Corrigé de la série D"

    <ol class="auto-corrige">
    <li value="1"><strong class="auto-resultat">Réponse B</strong> : Réponse : <span class="arithmatex">\(x=-1\)</span> ou <span class="arithmatex">\(x=5\)</span>.</li>
    <li value="2"><strong class="auto-resultat">Réponse B</strong> : Réponse : <span class="arithmatex">\((2)(-2)&lt;0\)</span>.</li>
    <li value="3"><strong class="auto-resultat">Réponse A</strong> : Réponse : <span class="arithmatex">\(\{-4;2\}\)</span>.</li>
    <li value="4"><strong class="auto-resultat">Réponse B</strong> : Réponse : entre les bornes.</li>
    <li value="5"><strong class="auto-resultat">Réponse C</strong> : Réponse : <span class="arithmatex">\(1\)</span> et <span class="arithmatex">\(-6\)</span>.</li>
    <li value="6"><strong class="auto-resultat">Réponse B</strong> : Réponse : les racines.</li>
    </ol>
    <div class="auto-methode"><strong>Méthode.</strong> QCM de signe : racines, intervalles, test de signe.</div>
    <div class="auto-vigilance"><strong>Vigilance.</strong> Le mot « factorisé » signale souvent une lecture directe.</div>
