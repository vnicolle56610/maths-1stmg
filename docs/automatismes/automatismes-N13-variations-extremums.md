## Série A — Signe de la dérivée

<p class="auto-meta">⏱ 6 min · Calculatrice interdite</p>

<div class="auto-consigne" markdown>
**Consigne.** Associer signe de <span class="arithmatex">\(f'\)</span> et variations de <span class="arithmatex">\(f\)</span>.
</div>

<ol class="auto-questions">
<li value="1">Si <span class="arithmatex">\(f'(x)&gt;0\)</span> sur un intervalle, <span class="arithmatex">\(f\)</span> est <span class="arithmatex">\(\ldots\)</span></li>
<li value="2">Si <span class="arithmatex">\(f'(x)&lt;0\)</span> sur un intervalle, <span class="arithmatex">\(f\)</span> est <span class="arithmatex">\(\ldots\)</span></li>
<li value="3">Si <span class="arithmatex">\(f'(x)=0\)</span> sur tout un intervalle, <span class="arithmatex">\(f\)</span> est <span class="arithmatex">\(\ldots\)</span></li>
<li value="4">Sur <span class="arithmatex">\([0;4]\)</span>, <span class="arithmatex">\(f'\)</span> est positive puis négative. <span class="arithmatex">\(f\)</span> augmente puis <span class="arithmatex">\(\ldots\)</span></li>
<li value="5">Sur <span class="arithmatex">\([0;5]\)</span>, <span class="arithmatex">\(f'\)</span> est négative puis positive. <span class="arithmatex">\(f\)</span> diminue puis <span class="arithmatex">\(\ldots\)</span></li>
<li value="6">Un maximum local apparaît souvent quand <span class="arithmatex">\(f'\)</span> passe de <span class="arithmatex">\(+\)</span> à <span class="arithmatex">\(\ldots\)</span></li>
</ol>

??? tip "Coup de pouce"

    <p><strong>Conseils</strong></p><ul><li>Le signe de <span class="arithmatex">\(f'\)</span> donne le sens de variation.</li><li>Lire les signes dans l'ordre des <span class="arithmatex">\(x\)</span>.</li><li>Un changement de signe peut signaler un extremum.</li></ul>
    <p><strong>Vigilance</strong></p><p>Le signe de <span class="arithmatex">\(f'\)</span>, pas le signe de <span class="arithmatex">\(f\)</span>, pilote les variations.</p>

??? success "Corrigé de la série A"

    <ol class="auto-corrige">
    <li value="1"><span class="arithmatex">\(\boxed{\text{croissante}}\)</span>.</li>
    <li value="2"><span class="arithmatex">\(\boxed{\text{décroissante}}\)</span>.</li>
    <li value="3"><span class="arithmatex">\(\boxed{\text{constante}}\)</span>.</li>
    <li value="4"><span class="arithmatex">\(\boxed{\text{diminue}}\)</span>.</li>
    <li value="5"><span class="arithmatex">\(\boxed{\text{augmente}}\)</span>.</li>
    <li value="6"><span class="arithmatex">\(\boxed{-}\)</span>.</li>
    </ol>
    <div class="auto-methode"><strong>Méthode.</strong> Quand <span class="arithmatex">\(f'\)</span> est positive, les pentes des tangentes sont positives : la fonction monte.</div>
    <div class="auto-vigilance"><strong>Vigilance.</strong> Une fonction peut être positive et décroissante : ne pas confondre signe et variation.</div>

## Série B — Tableau de variations

<p class="auto-meta">⏱ 6 min · Calculatrice interdite</p>

<div class="auto-consigne" markdown>
**Consigne.** Lire des extremums dans une description de variations.
</div>

<ol class="auto-questions">
<li value="1">Une fonction augmente de <span class="arithmatex">\(x=0\)</span> à <span class="arithmatex">\(x=3\)</span>, puis diminue. Quel type d'extremum en <span class="arithmatex">\(x=3\)</span> ?</li>
<li value="2">Une fonction diminue de <span class="arithmatex">\(x=1\)</span> à <span class="arithmatex">\(x=4\)</span>, puis augmente. Quel type d'extremum en <span class="arithmatex">\(x=4\)</span> ?</li>
<li value="3">Si <span class="arithmatex">\(f(3)=18\)</span> et <span class="arithmatex">\(f\)</span> admet un maximum en <span class="arithmatex">\(x=3\)</span>, la valeur maximale est <span class="arithmatex">\(\ldots\)</span></li>
<li value="4">Si <span class="arithmatex">\(C(5)=120\)</span> et <span class="arithmatex">\(C\)</span> admet un minimum en <span class="arithmatex">\(q=5\)</span>, le coût minimal est <span class="arithmatex">\(\ldots\)</span></li>
<li value="5">Si <span class="arithmatex">\(f'\)</span> passe de négatif à positif en <span class="arithmatex">\(2\)</span>, <span class="arithmatex">\(f\)</span> admet un <span class="arithmatex">\(\ldots\)</span></li>
<li value="6">Si <span class="arithmatex">\(f'\)</span> passe de positif à négatif en <span class="arithmatex">\(7\)</span>, <span class="arithmatex">\(f\)</span> admet un <span class="arithmatex">\(\ldots\)</span></li>
</ol>

??? tip "Coup de pouce"

    <p><strong>Conseils</strong></p><ul><li>Augmente puis diminue : maximum.</li><li>Diminue puis augmente : minimum.</li><li>La valeur de l'extremum est une image.</li></ul>
    <p><strong>Vigilance</strong></p><p>L'abscisse de l'extremum et la valeur de l'extremum ne sont pas le même nombre.</p>

??? success "Corrigé de la série B"

    <ol class="auto-corrige">
    <li value="1"><span class="arithmatex">\(\boxed{\text{maximum}}\)</span>.</li>
    <li value="2"><span class="arithmatex">\(\boxed{\text{minimum}}\)</span>.</li>
    <li value="3"><span class="arithmatex">\(\boxed{18}\)</span>.</li>
    <li value="4"><span class="arithmatex">\(\boxed{120}\)</span> euros.</li>
    <li value="5"><span class="arithmatex">\(\boxed{\text{minimum}}\)</span>.</li>
    <li value="6"><span class="arithmatex">\(\boxed{\text{maximum}}\)</span>.</li>
    </ol>
    <div class="auto-methode"><strong>Méthode.</strong> Un extremum se décrit par son abscisse et sa valeur.</div>
    <div class="auto-vigilance"><strong>Vigilance.</strong> Dire « maximum <span class="arithmatex">\(3\)</span> » est ambigu : <span class="arithmatex">\(3\)</span> peut être une abscisse, pas la valeur.</div>

## Série C — Optimisation en gestion

<p class="auto-meta">⏱ 7 min · Calculatrice interdite</p>

<div class="auto-consigne" markdown>
**Consigne.** Interpréter un extremum dans un contexte.
</div>

<ol class="auto-questions">
<li value="1">Un bénéfice <span class="arithmatex">\(B(q)\)</span> est maximal pour <span class="arithmatex">\(q=40\)</span> et <span class="arithmatex">\(B(40)=900\)</span>. Que signifie <span class="arithmatex">\(40\)</span> ?</li>
<li value="2">Dans le même contexte, que signifie <span class="arithmatex">\(900\)</span> ?</li>
<li value="3">Un coût <span class="arithmatex">\(C(q)\)</span> diminue puis augmente. Quel objectif de gestion cela suggère-t-il ?</li>
<li value="4">Si <span class="arithmatex">\(R'(p)&gt;0\)</span> sur <span class="arithmatex">\([5;12]\)</span>, que fait la recette <span class="arithmatex">\(R\)</span> quand le prix <span class="arithmatex">\(p\)</span> augmente sur cet intervalle ?</li>
<li value="5">Si <span class="arithmatex">\(B'(q)&lt;0\)</span> après <span class="arithmatex">\(q=60\)</span>, que devient le bénéfice après <span class="arithmatex">\(60\)</span> unités ?</li>
<li value="6">Un coût minimal de <span class="arithmatex">\(350\)</span> euros est atteint pour <span class="arithmatex">\(25\)</span> objets. Donner la phrase de conclusion.</li>
</ol>

??? tip "Coup de pouce"

    <p><strong>Conseils</strong></p><ul><li>Identifier la grandeur optimisée : coût, recette, bénéfice.</li><li>Une abscisse est souvent une quantité ou un prix.</li><li>Une image est souvent un montant.</li></ul>
    <p><strong>Vigilance</strong></p><p>Une conclusion doit répondre avec les unités et le contexte.</p>

??? success "Corrigé de la série C"

    <ol class="auto-corrige">
    <li value="1"><span class="arithmatex">\(40\)</span> est la <span class="arithmatex">\(\boxed{\text{quantité à produire/vendre}}\)</span>.</li>
    <li value="2"><span class="arithmatex">\(900\)</span> est le <span class="arithmatex">\(\boxed{\text{bénéfice maximal}}\)</span> en euros.</li>
    <li value="3">Chercher la <span class="arithmatex">\(\boxed{\text{quantité qui minimise le coût}}\)</span>.</li>
    <li value="4">Elle <span class="arithmatex">\(\boxed{\text{augmente}}\)</span>.</li>
    <li value="5">Il <span class="arithmatex">\(\boxed{\text{diminue}}\)</span>.</li>
    <li value="6">Le coût minimal est de <span class="arithmatex">\(\boxed{350}\)</span> euros pour <span class="arithmatex">\(\boxed{25}\)</span> objets.</li>
    </ol>
    <div class="auto-methode"><strong>Méthode.</strong> En optimisation, le calcul mathématique doit aboutir à une décision interprétable.</div>
    <div class="auto-vigilance"><strong>Vigilance.</strong> Une réponse sans unité ou sans contexte est incomplète.</div>

## Série D — QCM : avant DS

<p class="auto-meta">⏱ 7 min · Calculatrice interdite</p>

<div class="auto-consigne" markdown>
**Consigne.** Choisir la bonne réponse.
</div>

<ol class="auto-questions">
<li value="1">Si <span class="arithmatex">\(f'(x)&gt;0\)</span> sur <span class="arithmatex">\([1;6]\)</span>, alors <span class="arithmatex">\(f\)</span> est<ol class="auto-choix" type="A"><li>décroissante</li><li>croissante</li><li>négative</li><li>nulle</li></ol></li>
<li value="2">Si <span class="arithmatex">\(f'\)</span> passe de <span class="arithmatex">\(+\)</span> à <span class="arithmatex">\(-\)</span>, <span class="arithmatex">\(f\)</span> admet<ol class="auto-choix" type="A"><li>un minimum</li><li>un maximum</li><li>aucune variation</li><li>une racine</li></ol></li>
<li value="3">La valeur maximale de <span class="arithmatex">\(f\)</span> est<ol class="auto-choix" type="A"><li>une abscisse</li><li>une image</li><li>une pente</li><li>un coefficient</li></ol></li>
<li value="4">Pour <span class="arithmatex">\(f(x)=x^2-4x+7\)</span>, <span class="arithmatex">\(f'(x)=\)</span><ol class="auto-choix" type="A"><li><span class="arithmatex">\(x-4\)</span></li><li><span class="arithmatex">\(2x-4\)</span></li><li><span class="arithmatex">\(2x+7\)</span></li><li><span class="arithmatex">\(x^2-4\)</span></li></ol></li>
<li value="5">Si <span class="arithmatex">\(f'(x)=2x-4\)</span>, le changement de signe se fait en<ol class="auto-choix" type="A"><li><span class="arithmatex">\(x=0\)</span></li><li><span class="arithmatex">\(x=2\)</span></li><li><span class="arithmatex">\(x=4\)</span></li><li><span class="arithmatex">\(x=-2\)</span></li></ol></li>
<li value="6">Un coût minimal correspond à<ol class="auto-choix" type="A"><li>la plus petite valeur du coût</li><li>la plus grande quantité</li><li>une pente positive</li><li>un taux d'évolution</li></ol></li>
</ol>

??? tip "Coup de pouce"

    <p><strong>Conseils</strong></p><ul><li>Commencer par dériver si nécessaire.</li><li>Étudier ensuite le signe de <span class="arithmatex">\(f'\)</span>.</li><li>Terminer par l'interprétation.</li></ul>
    <p><strong>Vigilance</strong></p><p>Un tableau de variations ne remplace pas la phrase de conclusion.</p>

??? success "Corrigé de la série D"

    <ol class="auto-corrige">
    <li value="1"><strong class="auto-resultat">Réponse B</strong> : croissante</li>
    <li value="2"><strong class="auto-resultat">Réponse B</strong> : un maximum</li>
    <li value="3"><strong class="auto-resultat">Réponse B</strong> : une image</li>
    <li value="4"><strong class="auto-resultat">Réponse B</strong> : <span class="arithmatex">\(2x-4\)</span></li>
    <li value="5"><strong class="auto-resultat">Réponse B</strong> : <span class="arithmatex">\(2x-4=0\)</span>.</li>
    <li value="6"><strong class="auto-resultat">Réponse A</strong> : la plus petite valeur du coût</li>
    </ol>
    <div class="auto-methode"><strong>Méthode.</strong> Le schéma fiable : dérivée <span class="arithmatex">\(\rightarrow\)</span> signe <span class="arithmatex">\(\rightarrow\)</span> variations <span class="arithmatex">\(\rightarrow\)</span> extremum <span class="arithmatex">\(\rightarrow\)</span> contexte.</div>
    <div class="auto-vigilance"><strong>Vigilance.</strong> Le signe de <span class="arithmatex">\(f'\)</span> n'est pas le signe de <span class="arithmatex">\(f\)</span>.</div>
