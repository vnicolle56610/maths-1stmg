    Automatismes N07 — Second degré factorisé : racines, signe et problèmes

    24 questions sans calculatrice, réparties en 4 séries courtes à faire en quelques minutes. Chercher d'abord seul, puis ouvrir le corrigé.

    ⚡ Faire le QCM interactif 📄 Diaporama PDF à projeter 📖 Revoir la notion

    Série A — Racines et produit nul

    ⏱ 6 min · Calculatrice interdite

    Consigne. Résoudre mentalement des équations produit nul.

    1. Résoudre \((x-2)(x+5)=0\).
    2. Donner les racines de \(3(x-1)(x-4)\).
    3. Quel est le signe de \(x-3\) pour \(x=5\) ?
    4. Quel est le signe de \((x-1)(x-4)\) pour \(x=0\) ?
    5. Quel est le signe de \((x-1)(x-4)\) pour \(x=2\) ?
    6. Quel est le signe de \((x-1)(x-4)\) pour \(x=5\) ?
    Coup de pouce

    Conseils

    • Produit nul : un facteur nul suffit.
    • Pour un signe, tester une valeur simple.
    • Attention aux facteurs \(x+a\).

    Vigilance

    Ne pas inverser la racine de \(x+5\) : elle vaut \(-5\).

    Corrigé de la série A

    1. \(\mathscr S=\)\(\boxed{\{-5\,;\,2\}}\).
    2. Les racines sont \(\boxed{1}\) et \(\boxed{4}\).
    3. \(5-3=2\), signe \(\boxed{\text{positif}}\).
    4. \((-1)(-4)=4\), signe \(\boxed{\text{positif}}\).
    5. \((1)(-2)=-2\), signe \(\boxed{\text{négatif}}\).
    6. \((4)(1)=4\), signe \(\boxed{\text{positif}}\).
    Méthode. Pour une forme factorisée, les racines et le signe se lisent par facteurs.
    Vigilance. Tester une valeur ne remplace pas une étude complète, mais aide à construire le signe.

    Série B — Signe d'une forme factorisée

    ⏱ 7 min · Calculatrice interdite

    Consigne. Lire les racines puis le signe d'un polynôme factorisé.

    1. Donner les racines de \(P(x)=-2(x+3)(x-1)\).
    2. Quel est le signe de \(P(x)\) sur \(]-3;1[\) ?
    3. Pour \(Q(x)=(x-2)(x-6)\), résoudre \(Q(x)>0\).
    4. Pour \(Q(x)=(x-2)(x-6)\), résoudre \(Q(x)<0\).
    5. Pour \(Q(x)=(x-2)(x-6)\), que valent \(Q(2)\) et \(Q(6)\) ?
    6. Un bénéfice est \(B(q)=(q-2)(6-q)\). Pour quelles quantités \(B(q)>0\) ?
    Coup de pouce

    Conseils

    • Repérer d'abord les racines.
    • Tester un intervalle.
    • Conclure en contexte.

    Vigilance

    Le coefficient devant les facteurs compte.

    Corrigé de la série B

    1. Racines : \(\boxed{-3}\) et \(\boxed{1}\).
    2. Entre les racines : \((x+3)>0\), \((x-1)<0\), puis \(-2\) rend \(P(x)\) \(\boxed{\text{positif}}\).
    3. \(\mathscr S=\)\(\boxed{]-\infty;2[\cup]6;+\infty[}\).
    4. \(\mathscr S=\boxed{]2;6[}\).
    5. \(Q(2)=\boxed{0}\) et \(Q(6)=\boxed{0}\).
    6. \(B(q)>0\) pour \(\boxed{2<q<6}\).
    Méthode. Lire les racines, découper la droite, puis déterminer le signe sur chaque intervalle.
    Vigilance. Dans un problème, les bornes où le bénéfice est nul ne sont pas des bénéfices positifs.

    Série C — Vérifier et factoriser dans des cas simples

    ⏱ 7 min · Calculatrice interdite

    Consigne. Utiliser une racine connue pour factoriser ou conclure.

    1. Vérifier que \(2\) est racine de \(P(x)=x^2-5x+6\).
    2. Si les racines de \(P\) sont \(2\) et \(3\) et le coefficient dominant vaut \(1\), écrire \(P(x)\) sous forme factorisée.
    3. Factoriser \(x^2-4x\).
    4. Donner les racines de \(x(x-4)\).
    5. Résoudre \(x(x-4)\geqslant 0\).
    6. Quelle méthode est interdite ici pour chercher les racines ?
    Coup de pouce

    Conseils

    • Vérifier : remplacer \(x\).
    • Factoriser si c'est visible.
    • Lire le signe par intervalles.

    Vigilance

    Pas de recherche systématique par formule.

    Corrigé de la série C

    1. \(P(2)=4-10+6=\boxed{0}\), donc \(2\) est racine.
    2. \(P(x)=\boxed{(x-2)(x-3)}\).
    3. \(x^2-4x=\boxed{x(x-4)}\).
    4. Racines : \(\boxed{0}\) et \(\boxed{4}\).
    5. \(\mathscr S=\)\(\boxed{]-\infty;0]\cup[4;+\infty[}\).
    6. \(\boxed{\text{Le discriminant}}\) n'est pas une méthode du programme.
    Méthode. Quand une racine est connue, on exploite une factorisation simple ou visible.
    Vigilance. Le discriminant ne doit pas être introduit en Première STMG.

    Série D — QCM - second degré factorisé

    ⏱ 7 min · Calculatrice interdite

    Consigne. Choisir une seule réponse. Aucune justification demandée.

    1. Les racines de \(2(x+1)(x-5)\) sont :
      1. \(1\) et \(5\)
      2. \(-1\) et \(5\)
      3. \(-1\) et \(-5\)
      4. \(2\) et \(5\)
    2. Pour \(P(x)=(x-3)(x-7)\), \(P(5)\) est :
      1. positif
      2. négatif
      3. nul
      4. impossible
    3. \((x+4)(x-2)=0\) a pour ensemble solution :
      1. \(\{-4;2\}\)
      2. \(\{4;2\}\)
      3. \(\{-4;-2\}\)
      4. \(\{0;2\}\)
    4. Si \(B(q)>0\) pour \(3<q<9\), le bénéfice est positif :
      1. aux bornes
      2. entre les bornes
      3. partout
      4. jamais
    5. La forme \(-3(x-1)(x+6)\) possède :
      1. aucune racine
      2. une racine
      3. deux racines visibles
      4. trois racines
    6. Pour trouver le signe, on doit d'abord repérer :
      1. les unités
      2. les racines
      3. le nombre de questions
      4. le discriminant
    Coup de pouce

    Conseils

    • Traiter chaque facteur séparément.
    • Entre deux racines, tester une valeur simple.
    • Une seule réponse est correcte.

    Vigilance

    Ne pas choisir une méthode hors programme.

    Corrigé de la série D

    1. Réponse B : Réponse : \(x=-1\) ou \(x=5\).
    2. Réponse B : Réponse : \((2)(-2)<0\).
    3. Réponse A : Réponse : \(\{-4;2\}\).
    4. Réponse B : Réponse : entre les bornes.
    5. Réponse C : Réponse : \(1\) et \(-6\).
    6. Réponse B : Réponse : les racines.
    Méthode. QCM de signe : racines, intervalles, test de signe.
    Vigilance. Le mot « factorisé » signale souvent une lecture directe.
