    Automatismes N06 — Fonctions du second degré : paraboles et formes simples

    24 questions sans calculatrice, réparties en 4 séries courtes à faire en quelques minutes. Chercher d'abord seul, puis ouvrir le corrigé.

    ⚡ Faire le QCM interactif 📄 Diaporama PDF à projeter 📖 Revoir la notion

    Série A — Réactivation : fonctions et calcul

    ⏱ 6 min · Calculatrice interdite

    Consigne. Réactiver les calculs utiles avant le second degré.

    1. Soit \(f(x)=2x+3\). Calculer \(f(5)\).
    2. Si \(f(0)=3\) et \(f(4)=11\), calculer le taux de variation entre \(0\) et \(4\).
    3. Augmenter de \(20\,\%\), c'est multiplier par quel coefficient ?
    4. Résoudre mentalement \(2x-6=0\).
    5. Quel est le signe de \(x-4\) pour \(x=6\) ?
    6. Soit \(h(x)=x^2\). Calculer \(h(-4)\).
    Coup de pouce

    Conseils

    • Commencer par remplacer \(x\).
    • Pour un carré, le résultat est positif.
    • Réactiver coefficients et signes.

    Vigilance

    Ne pas écrire \((-4)^2=-16\).

    Corrigé de la série A

    1. \(f(5)=\)\(2\times5+3=\)\(\boxed{13}\).
    2. \(\dfrac{11-3}{4-0}=\)\(\dfrac{8}{4}=\)\(\boxed{2}\).
    3. \(\boxed{1{,}20}\).
    4. \(2x=6\), donc \(x=\boxed{3}\).
    5. \(6-4=2\), signe \(\boxed{\text{positif}}\).
    6. \((-4)^2=\boxed{16}\).
    Méthode. Remplacer, simplifier, conclure : une étape propre évite les erreurs de signe.
    Vigilance. Le carré d'un nombre négatif est positif.

    Série B — Paraboles : allure et sommet

    ⏱ 6 min · Calculatrice interdite

    Consigne. Reconnaître les formes simples du second degré.

    1. Soit \(p(x)=x^2\). Calculer \(p(-3)\).
    2. Soit \(q(x)=-x^2\). Calculer \(q(2)\).
    3. Pour \(f(x)=x^2+5\), donner le sommet de la parabole.
    4. Pour \(g(x)=-2x^2+1\), la parabole est-elle ouverte vers le haut ou vers le bas ?
    5. Donner l'axe de symétrie de la parabole \(y=x^2-4\).
    6. Pour \(h(x)=x^2+3\), comparer \(h(-2)\) et \(h(2)\).
    Coup de pouce

    Conseils

    • Le signe de \(a\) donne l'ouverture.
    • La forme \(x^2+c\) décale verticalement.
    • L'axe de \(x^2+c\) est l'axe des ordonnées.

    Vigilance

    Aucune formule générale du sommet n'est nécessaire ici.

    Corrigé de la série B

    1. \(p(-3)=(-3)^2=\boxed{9}\).
    2. \(q(2)=-(2^2)=\boxed{-4}\).
    3. Sommet : \(\boxed{(0;5)}\).
    4. Comme \(a=-2<0\), elle est ouverte \(\boxed{\text{vers le bas}}\).
    5. Axe de symétrie : \(\boxed{x=0}\).
    6. \(h(-2)=7\) et \(h(2)=7\), donc \(\boxed{h(-2)=h(2)}\).
    Méthode. Pour \(a x^2+c\), le sommet est sur l'axe des ordonnées.
    Vigilance. Ne pas utiliser le discriminant : il n'intervient pas dans cette notion.

    Série C — Formes simples du second degré

    ⏱ 7 min · Calculatrice interdite

    Consigne. Associer expression, racines visibles et élément caractéristique.

    1. Donner les racines visibles de \(P(x)=(x-1)(x-5)\).
    2. Donner les racines visibles de \(Q(x)=-(x+2)(x-4)\).
    3. Factoriser mentalement \(x^2-9\).
    4. Pour \(f(x)=2x^2+3\), quelle est la valeur minimale ?
    5. Pour \(g(x)=-x^2+5\), quelle est la valeur maximale ?
    6. Dans \(a(x-r_1)(x-r_2)\), quelles sont les racines visibles ?
    Coup de pouce

    Conseils

    • Un produit est nul si l'un des facteurs est nul.
    • La forme factorisée donne les racines directement.
    • Une parabole ouverte vers le haut a un minimum.

    Vigilance

    Ne pas développer si la forme factorisée suffit.

    Corrigé de la série C

    1. \(\boxed{1}\) et \(\boxed{5}\).
    2. \(\boxed{-2}\) et \(\boxed{4}\).
    3. \(x^2-9=\boxed{(x-3)(x+3)}\).
    4. La valeur minimale est \(\boxed{3}\), atteinte pour \(x=0\).
    5. La valeur maximale est \(\boxed{5}\), atteinte pour \(x=0\).
    6. Les racines visibles sont \(\boxed{r_1}\) et \(\boxed{r_2}\).
    Méthode. La forme factorisée est faite pour lire les zéros.
    Vigilance. Un facteur comme \(x+2\) s'annule pour \(x=-2\).

    Série D — QCM - second degré simple

    ⏱ 7 min · Calculatrice interdite

    Consigne. Choisir une seule réponse. Aucune justification demandée.

    1. La courbe de \(x\mapsto -x^2+4\) est :
      1. une droite
      2. une parabole ouverte vers le haut
      3. une parabole ouverte vers le bas
      4. un point
    2. Le sommet de \(x\mapsto x^2-6\) est :
      1. \((0;6)\)
      2. \((0;-6)\)
      3. \((-6;0)\)
      4. \((6;0)\)
    3. Les racines de \((x-3)(x+1)\) sont :
      1. \(3\) et \(1\)
      2. \(-3\) et \(1\)
      3. \(3\) et \(-1\)
      4. \(-3\) et \(-1\)
    4. Pour \(f(x)=x^2+2\), on a :
      1. \(f(-1)=1\)
      2. \(f(-1)=3\)
      3. \(f(-1)=-3\)
      4. \(f(-1)=-1\)
    5. L'axe de symétrie de \(y=-3x^2+7\) est :
      1. \(x=7\)
      2. \(y=7\)
      3. \(x=0\)
      4. \(y=0\)
    6. La forme qui donne directement les racines est :
      1. développée
      2. factorisée
      3. décimale
      4. graphique seulement
    Coup de pouce

    Conseils

    • Identifier d'abord la forme.
    • Le signe placé devant \(x^2\) donne l'ouverture.
    • Un facteur nul donne une racine.

    Vigilance

    Le discriminant est hors programme : ne pas le chercher.

    Corrigé de la série D

    1. Réponse C : Réponse : le coefficient de \(x^2\) est négatif.
    2. Réponse B : Réponse : sommet \((0;-6)\).
    3. Réponse C : Réponse : \(x=3\) ou \(x=-1\).
    4. Réponse B : Réponse : \((-1)^2+2=3\).
    5. Réponse C : Réponse : axe \(x=0\).
    6. Réponse B : Réponse : la forme factorisée.
    Méthode. Lire ce que la forme donne directement : sommet, ouverture ou racines.
    Vigilance. Ne pas développer si la réponse est lisible sans calcul long.
